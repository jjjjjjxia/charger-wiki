    IEC 61851-1 安规测试项目详解¶

    类型: concept (method) 创建时间: 2026-07-22 最后更新: 2026-07-22 来源: raw/欧标/桩标准/IEC 61851-1-2017-1.md 标签: #安规测试 #IEC61851 #绝缘 #耐压 #IP等级

    摘要¶

    IEC 61851-1 第12章规定了 EV 供电设备的结构要求和测试项目。本文档汇总各项安规测试的关键参数与判定标准，供认证流程参考。所有参数均来源于标准原文。

    详情¶

    1. IP 防护等级（§12.4）¶

    依据 IEC 60529。

    使用场景 部位 最低 IP 等级
    室内 外壳 IP41
    室外 外壳 IP44
    室内 连接器（插合时） IP21
    室内 Case B 连接器（未插合） IP24
    室外 连接器（插合时） IP44
    室外 连接器/插座（未插合） IP24

    IPX4 可通过插座/连接器与盖板/外壳的组合实现。

    2. 绝缘电阻（§12.5）¶

    测试电压：500V DC，施加于所有输入/输出（含电源）与可触及部件之间。

    设备类别 绝缘电阻要求
    Class I R > 1 MΩ
    Class II R > 7 MΩ
    • 测试条件：湿热连续测试后（IEC 60068-2-78, 40°C ±2°C, 93% RH, 4天），施加电压 1 分钟
    • ELV 电路须在测试中连接至可触及部件

    3. 接触电流（§12.6）¶

    依据 IEC 60990 测量。测试电压：1.1 × 最大额定电压。

    测量位置 Class I Class II
    网络极 ↔ 可触及金属部件 ≤ 3.5 mA ≤ 0.25 mA
    网络极 ↔ 不可触及金属部件（双重绝缘） N/A ≤ 3.5 mA
    不可触及 ↔ 可触及部件（附加绝缘） N/A ≤ 0.5 mA
    • 测试条件：湿热测试后 1 小时内，设备带阻性负载在额定输出功率下运行

    4. 介电耐压（§12.7）¶

    4.1 AC 耐压（§12.7.1）¶

    电源频率 50/60Hz，施加 1 分钟。

    设备类别 测试电压
    Class I (Un + 1200V) rms
    Class II 2 × (Un + 1200V) rms
    AC↔ELV 间双重/加强绝缘 2 × (Un + 1200V) rms

    Un = 中性点接地系统的标称相电压。可用等值 DC 峰值电压替代 AC 测试。

    4.2 冲击耐压（§12.7.2）¶

    波形 1.2μs/50μs，依据 IEC 60664-1。

    连接方式 过电压类别
    直连公共 AC 电网 类别 IV
    永久连接 类别 III
    插头连接 类别 II
    Case C 插座/连接器 类别 II

    5. 温升（§12.8）¶

    符合 IEC TS 61439-7。

    6. 湿热功能测试（§12.9）¶

    依据 IEC 60068-2-30 (Test Db)，40±3°C，95% RH。

    场景 条件
    室内 6 个 24h 循环
    室外 2 × 12 天周期，每周期 5 个 24h 循环

    判定：测试后通过 Annex A 正常时序测试（A.4.7）。

    7. 最低温度功能测试（§12.10）¶

    依据 IEC 60068-2-1 (Test Ab)，预处理 16±1 小时。

    场景 温度
    室内 -5°C
    室外 -25°C

    制造商可声明确认更低温度值。

    判定：预处理后立即通过 Annex A 时序测试（A.4.7）。

    8. 机械强度（§12.11）¶

    • Mode 2 EV 供电设备：外壳最低防机械冲击等级 IK08（依据 IEC 62262）
    • 测试后判定标准：
    • IP 等级（§12.5）不得降低
    • 无部件移动、松动、脱落或变形至影响安全功能
    • 应力释放要求仍满足（如适用）
    • 带电部件间爬电距离和电气间隙不低于最小可接受值
    • 无其他可能增加火灾或电击风险的损坏

    防触电保护 — 残余电流保护（§8.5）¶

    要求 参数
    额定剩余动作电流 ≤ 30 mA
    RCD 类型 至少 Type A
    DC 故障电流保护 Type B RCD，或 Type A + DC >6mA 断开装置
    适用标准 IEC 61008-1 / IEC 61009-1 / IEC 60947-2 / IEC 62423
    断开方式 断开所有带电导体
