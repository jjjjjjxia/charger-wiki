    UL 2231-1:2016 — 电动汽车供电电路人身保护系统 通用要求¶

    类型: concept 创建时间: 2026-07-30 最后更新: 2026-07-30 来源: UL 2231-1:2016 全文

    摘要¶

    UL 2231-1 标题为 Personnel Protection Systems for Electric Vehicle (EV) Supply Circuits: General Requirements（电动汽车供电电路人身保护系统：通用要求），第二版原始日期 September 7, 2012，标题页重印及 ANSI 认定日期为 August 26, 2016（含至 2016-08-26 的修订）。它是北美三国协调标准，同时发布为 NMX-J-668-1-ANCE 第 2 版、CAN/CSA-C22.2 No. 281.1-12 第 1 版、UL 2231-1 第 2 版[1]。

    该标准只规定范围、定义与保护系统所需具备的特征（保护要素的组合规则），不含性能与结构要求——后者由 concepts/standard-ul-2231-2（UL 2231-2）规定（§1.10）。它被 concepts/standard-ul-2202 §9.1.1 与 concepts/standard-ul-2594 §9.2.1 强制引用，是北美 EVSE 触电防护体系的顶层文件[1]。

    范围（§1 Scope）¶

    适用[1]：用于降低用户从可触及部件遭电击风险的装置与系统，适用于接地或隔离的电动汽车充电电路（车外或车载）。

    前置条件（§1.3–§1.5）： - §1.3 车辆须至少满足其一：充电期间可连接设备接地导体（除非车辆采用加强/双重绝缘或整车电路与供电电路隔离）、可连接接地监测导体、加强绝缘或双重绝缘、载流导体与车架无直接连接 - §1.4 充电系统至车辆的接地路径阻抗 ≤ 不接地导体阻抗 - §1.5 充电系统任何可触及部件可获得的连续电流 < 70 mA RMS

    §1.6 装置应在以下情形切断负载电路：(a) 对地故障电流超过某预定值（该值小于供电电路过流保护器动作值）；(b) 接地路径开路或阻抗过高；(c) 隔离（不接地）系统上检出对地通路。

    §1.7 适用的电气系统：≤150 Vrms 时端接地或中点接地；>150 Vrms 时中点接地；或隔离（不接地）。

    不适用（§1.9）：美国/墨西哥/加拿大国家电气规程下用于 120 Vrms 或 127 Vrms 对地、60 Hz 接地电路的人身保护 GFCI（由 UL 943 / CSA C22.2 No.144.1 / NMX-J-520-ANCE 覆盖）[1]。

    保护理念（§4.1 Basis of requirements）¶

    • §4.1.1 要求旨在降低肌肉强直（muscle tetanization，含 let-go 摆脱不能）与心室颤动（ventricular fibrillation）的可能性
    • §4.1.2 绝缘是首要手段；绝缘失效（高阻或低阻）时，须至少有一个二次保护机制分别应对上述两种效应。单一机制可同时应对一种或两种，例如 CCID 可同时应对心室颤动与 let-go，而可靠接地（带失地中断的监测接地）应对 let-go 危害。因绝缘失效可能带来误动作困扰，故障条件下允许发生惊愕反应（startle reaction）
    • §4.1.3 保护电路自身可提供的电流不得构成危险条件
    • §4.2.2 评估须逐一针对充电系统的每个可触及部件，分别相对大地与其他同时可触及部件判定防护是否充分

    三类保护要素（§5 Protective Elements）¶

    要素 定义与要求
    CCID（Charging Circuit-Interrupting Device，充电电路中断装置） §5.1.1 持续监测接地系统中所有载流导体的差动电流（等于装置负载侧的对地电流），超过预定值 5 MIU 或 20 MIU 时快速切断负载侧电源。最大分断时间由 UL 2231-2 规定。装置以 CCID5 / CCID20 标识
    GM/I（Grounding Monitor/Interrupter，接地监测/中断器） §5.2.1 监测设备接地连续性；启动时若接地不连续则不得给负载端上电，运行中失地则切断电路。监测手段：在被监测接地路径中持续通入非危险的循环测试电流，或持续监测接地路径末端相对系统可靠接地点的电压。系统无接地故障时也须能感知接地缺失并断开
    IM/I（Isolation Monitor/Interrupter，隔离监测/中断器） §5.3.1 监测隔离电路对地绝缘，电阻低于设定点时断开电源；§5.3.1A 须监测对称与不对称对地电阻；§5.3.1B 低于设定点时不得初始上电；§5.3.1C 连续监测型须在低于设定点时断开。§5.3.2–§5.3.6 规定车载（on-board）/车外（off-board）监测器单独或组合使用时的功能与互不干扰要求；§5.3.7 若监测器插入充电机后变为接地，则须在充电开始前完成隔离检查，之后不再运行；设计为隔离运行的电路须全程监测
    IM/I/SC 隔离监测/中断器 with self check——带自动监督电路，定期检查隔离监测器工作是否正常，异常时不允许上电或断开负载端（§2.12）

    MIU（Measurement Indication Unit，测量指示单位）¶

    §2.15：MIU = 图 1 或图 2 测量仪表输出电压（mV 或峰值 mV）÷ 500 Ω，与电流通过人体的生理效应相关。低频下 MIU 数值等于流过测量仪的毫安数；高频下 MIU 读数小于实际毫安数——例如 100 kHz 时，实际电流 70 mA 对应 0.5 MIU-RR[1]。

    保护系统组合规则（§6）¶

    要素缩写：BI 基本绝缘、DI 双重绝缘、RI 加强绝缘、CCID5/CCID20、GM/I 接地监测中断器、CLG 中点接地系统、CLG/I 带阻抗限制的中点接地系统、IM/I 隔离监测中断器、IM/I/SC 带自检的隔离监测中断器。

    Table 2 — 接地系统（§6.1）¶

    电压与条件 所需要素
    任意两导体间 0–15 Vrms BI
    任意两导体间 15–300 Vrms 且无导体对地 >150 Vrms BI + CCID5 或 BI + CCID20 + GM/I 或 DI + CCID20 或 RI + CCID20
    任意两导体间 150–300 Vrms 单相，或 150–260 Vrms 三相 BI + CCID5 + CLG 或 BI + CCID20 + GM/I + CLG 或 DI + CCID20 + CLG 或 RI + CCID20 + CLG
    任一导体对地 >150 Vrms BI + CCID20 + GM/I + CLG 或 DI + CCID20 + CLG 或 RI + CCID20 + CLG
    任一导体对地 >300 Vrms BI + CCID20 + GM/I + CLG/I 或 DI + CCID20 + CLG/I 或 RI + CCID20 + CLG/I
    任意两导体间 >1000 Vrms 不允许（§6.1.9）

    Table 3 — 隔离电路（§6.2）¶

    电压与条件 所需要素
    任意两导体间 0–15 Vrms BI
    任意两导体间 15–150 Vrms BI + IM/I
    任意两导体间 >150 Vrms BI + GM/I + IM/I 或 BI + IM/I/SC 或 DI + IM/I 或 RI + IM/I
    任意两导体间 >1000 Vrms 不允许（§6.2.5）
