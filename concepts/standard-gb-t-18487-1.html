    GB/T 18487.1-2023 电动汽车传导充电系统 第1部分：通用要求¶

    类型: concept (standard) 创建时间: 2026-07-22 最后更新: 2026-07-29 来源: GB/T 18487.1-2023 全文 标签: #国标 #GB/T #推荐性 #充电系统 #通用要求

    摘要¶

    GB/T 18487.1-2023 是中国电动汽车传导充电系统的基础通用标准，规定了充电系统分类、通用要求、通信、电击防护、连接、接口、结构、性能等全链条要求。该标准代替 GB/T 18487.1-2015，2024-04-01 实施，覆盖交流与直流充电，是充电桩产品设计与测试的核心依据之一。虽为推荐性标准（GB/T），但被 entities/certification-ccc 和 entities/certification-cqc 认证体系引用，实际约束力很强。

    适用范围（§1）¶

    • 非车载传导式供电设备，实现电动汽车可充电储能系统与供电网之间单向/双向能量流动
    • 供电网侧(A侧)额定电压：≤ 1000V AC 或 1500V DC
    • 电动汽车侧(B侧)额定最大电压：≤ 1000V AC 或 1500V DC
    • 适用于：纯电动汽车、可外接充电式混合动力汽车、燃料电池混合动力电动汽车
    • 不适用于：车载充电设备(GB/T 40432)、无轨电车、维护安全要求

    分类体系（§4）¶

    分类维度 类别
    供电网输入特性 交流供电网 / 直流供电网
    供电网连接方式 标准插头电缆组件 / 固定连接
    能量传输电流种类(B侧) 交流 / 直流 / 交直流
    使用环境 室内 / 室外
    安装使用场所 限制进入场所 / 非限制进入场所
    交流额定电压 单相 220V，三相 380V
    直流额定最大电压 500V / 750V / 1000V / 1250V
    交流额定电流 8A / 10A / 16A / 32A / 63A
    直流额定持续电流 10A ~ 800A（14档）
    安装方式 固定式(壁挂/支架/落地) / 非固定式(移动/便携)
    电击防护 Ⅰ类设备 / Ⅱ类设备

    充电模式使用条件（§5.1）¶

    ⚠️ 关键差异：GB/T 18487.1 明确禁止使用 Mode 1，与 IEC 61851（部分国家禁止）不同。详见 concepts/comparison-gb-vs-iec-safety。

    模式 国标要求 连接方式
    Mode 1 ⛔ 不应使用（明确禁止） —
    Mode 2 标准插座，单相交流；10A插座≤8A，GB/T 11918插座≤32A；须IC-CPD 标准插头电缆组件
    Mode 3 永久连接交流供电网；单相≤32A，三相>32A须连接方式C；须RCD A/B/C（D/E考虑中）
    Mode 4 直流供电设备；永久连接或标准插头/交流车辆插座 C/D/E（V2G仅C）

    电击防护（§7）¶

    接触电流限值（§7.1.4）¶

    稳态接触电流不应超过：

    条件 交流 直流
    正常运行 0.5 mA AC 2 mA DC
    单一故障 3.5 mA AC 10 mA DC
    • Ⅰ类设备接触电流超过 3.5mA(有效值)时，须符合 §12.1.2 特殊规定（隔离或加强接地）
    • 直流充电须提供附加防护，稳态接触电流不超过 GB/T 13870.1-2022 中 DC2 限值(b线)
    • 放电能量限值：正常 5μJ，单一故障 0.5mJ
    • 人体阻抗取值：575Ω（GB/T 13870.1-2022）
    • 直流绝缘电阻临界点：100Ω/V

    基本防护（§7.2）与故障防护（§7.3）¶

    • 基本防护：基本绝缘 / 外壳屏障 / 限制电压 / 稳态接触电流限值
    • 故障防护：保护联结、自动切断电源、剩余电流保护等
    • 模式 3/4 固定安装设备：保护接地导体和保护连接导体应固定连接
    • 存储能量（§7.7）：标准插头断开、车辆接口断开、供电接口断开、供电网断电时须限制存储能量
    • 接触器粘连（§7.9）：新增要求

    §7.4 保护接地导体¶

    • 所有模式：在交流供电网接地端子、直流供电网接地端子和车辆插头接地端子之间须提供保护接地导体
    • 保护接地导体须符合 GB/T 16895.3 的规定
    • 模式 3/4 永久连接供电网设备：不得使用开关或类似装置连接保护接地导体
    • 模式 4（附录B 控制导引）：车辆插头内未装熔断器时，保护导体最小截面积 ≥ 16mm²
    • 模式 4（附录C 控制导引）：保护导体最小截面积 ≥ 6mm²

    配置熔断器时，保护导体可与熔断器匹配选择。

    冲击电流（§10.7）¶

    §10.7.1 模式 2 和模式 3 的冲击电流¶

    交流供电设备在闭合接触器输出额定电压后，须能承受：

    时间段 冲击电流限值
    闭合后 100μs 内 230A 峰值
    随后 1s 内 30A（有效值）

    冲击电流波形和设置见 GB/T 41589-2022 图 29 和 9.8.2.1。也可按 GB/T 7251.7 对独立开关设备验证。保护装置不应因冲击电流跳闸。

    §10.7.2 模式 4 的冲击电流¶

    直流接触器接通时的冲击电流（峰值）须控制在 20A DC 以下。

    ⚠️ 与 IEC 61851-1 对比：IEC 规定 230A/100μs + 30A/1s（与国标一致），源自 ISO 17409。详见 concepts/standard-iec-61851-1 §12.2.6。

    性能要求（§12）¶

    接触电流测试（§12.1）¶

    条件 Ⅰ类设备 Ⅱ类设备
    正常工作 0.5mA AC / 2mA DC 0.25mA AC / 10mA DC
    故障条件 3.5mA AC / 10mA DC 0.5mA AC / 10mA DC
    • 测试方法：GB/T 12113-2003，测量网络选择依据电流大小
    • 湿热测试条件：GB/T 2423.3 恒定湿热 Ca（40°C±2°C，93%±3% RH，4天）后 1h 内测量
    • 试验电压：额定电压的 1.1 倍

    绝缘电阻（§12.2）¶

    测试条件 要求 测试方法
    常态 R ≥ 10 MΩ 500V DC，1min
    湿热后（Ⅰ类） R > 1 MΩ GB/T 2423.4 交变湿热 Db（40°C，2循环）后 30min 内
    湿热后（Ⅱ类） R > 7 MΩ 同上

    ⚠️ 与 IEC 差异：常态绝缘电阻国标要求 10MΩ，远高于 IEC 61851-1 的 1MΩ(Ⅰ类)/7MΩ(Ⅱ类)。详见 concepts/comparison-gb-vs-iec-safety。

    介电强度（§12.3）— 表4¶

    额定绝缘电压 Ui（线-线 AC/DC） 交流有效值 (V) 直流 (V)
    Ui ≤ 60 1000 1415
    60 < Ui ≤ 300 1500 2120
    300 < Ui ≤ 690 1890 2670
    690 < Ui ≤ 800 2000 2830
    800 < Ui ≤ 1000 2200 3110
    1000 < Ui ≤ 1500 —（仅直流） 3820
    • 持续 1 分钟工频交流（也可用直流）
    • 出厂试验允许电压高 10%，时间 1s
    • 泄漏电流 ≤ 10mA，不应出现击穿或闪络

    冲击耐压（§12.4）— 表5¶

    系统标称电压 冲击耐压试验电压 (V)
    ≤ 50V AC / 71V DC 500
    100V AC / 141V DC 800
    150V AC / 213V DC 1500
    300V AC / 424V DC 2500
    600V AC / 849V DC 4000
    1000V AC / 1500V DC 6000
    • 3次正极性 + 3次负极性标准雷电波（1.2/50μs，500Ω）
    • 过电压类别：直接连电网 Ⅳ / 永久连接 Ⅲ / 插头连接 Ⅱ

    结构要求（§11）¶

    剩余电流保护器 RCD（§11.3）¶

    设备类型 RCD 要求
    交流供电设备 A型+6mA DC监测 / A型+6mA监测装置 / B型（三选一）
    直流供电设备 交流侧须RCD（可用AC型）或加强绝缘/隔离
    • 额定剩余动作电流 IΔn ≤ 30mA
    • Mode 3 直流检测装置须符合 GB/T 40820-2021

    💡 国标允许 "A型+6mA DC监测" 方案，比 IEC（DC故障须B型）更灵活。详见 concepts/comparison-gb-vs-iec-safety。

    电涌保护器 SPD（§11.7）¶

    使用场景：模式 4 连接方式 C 的直流供电设备制造商宜根据现场环境和安装条件选配 SPD。

    配置场景包括但不限于： - 使用长直流电缆组件（> 10m） - 靠近防雷系统（LPS）的电缆组件

    §11.7.2 输入端瞬态过压：按 GB/T 18487.2-2017 附录E 施加标准雷电波短时冲击电压，供电设备须限制输出电压不超过：

    测试位置 电压限值
    DC+ 与 PE 之间 ≤ 2500V
    DC- 与 PE 之间 ≤ 2500V
    DC+ 和 DC- 之间 ≤ 直流充电电压 + 500V

    §12.6 雷电防护：SPD 安装与选型须根据供电设备安装场所，连接交流供电网时须满足 GB 50057-2010 中 6.4 的要求。

    IP 防护等级（§11.5）¶

    模式 室内 室外
    Mode 2（IC-CPD） 符合 GB/T 41589 符合 GB/T 41589
    Mode 3 / Mode 4 ≥ IP32 ≥ IP54

    过载保护和短路保护（§13）¶

    §13.1 通则¶

    • 过流保护装置须符合 GB/T 14048.2、GB/T 14048.9、GB/T 16917.1、GB/T 10963（所有部分）、GB/T 13539（所有部分）
    • 可同时使用的多连接点：可共用过载和短路保护（共用装置额定值 ≤ 最低连接点额定值）
    • 不可同时使用的多连接点：可共用保护装置

    §13.2 充电电缆过载保护¶

    • 供电设备须为连接方式 C 下各种尺寸电缆提供过载保护（除非输入侧已提供）
    • 过载保护可由断路器、熔断器或组合实现
    • 非断路器/熔断器方式：电流超过电缆额定值 1.3 倍时须在 1 分钟内断开充电

    §13.3 充电电缆短路保护 — I²t 限值¶

    设备类型 位置 I²t 限值
    模式 3（连接方式 A/B） 供电插座 ≤ 75,000 A²s
    模式 3（连接方式 C） 车辆插头 ≤ 80,000 A²s
    模式 4 车辆插头 ≤ 500,000 A²s

    模式 4 的 I²t 值由功率变换单元和熔断器（或类似装置）配合实现。

    ⚠️ 与 IEC 61851-1 对比：IEC 规定 Mode 3 插座 75,000 A²s、Case C 车辆连接器 80,000 A²s（与国标一致），但 IEC 未覆盖 Mode 4 的 I²t 限值。国标新增了模式 4 的 500,000 A²s 要求。详见 concepts/standard-iec-61851-1 §13.3。

    使用条件（§15）¶

    条件 室内 室外
    温度 -5°C ~ +40°C -25°C ~ +40°C
    湿度 40°C时≤50%（20°C时可90%） 25°C时短时可达100%
    污染等级 2 3
    海拔 ≤ 2000m ≤ 2000m
    • 海拔 >2000m 须按 GB/T 16935.1-2008 考虑电气间隙和爬电距离
    • 特殊环境（可燃气体、高海拔、腐蚀环境）须增加附加功能

    标识要求（§17）¶

    供电设备须至少标识：制造商标识、产品名称型号、序列号、生产日期、额定电压(V)、额定电流(A)。直流设备还须标识最大充放电功率(kW)、电压范围(V)、最大电流(A)。

    A.2.6 二极管存在性检测¶

    在能量传输前，供电设备应能通过检测控制导引电路上二极管 D1 的存在性来验证连接的是电动汽车而非负载设备。该检测应在供电设备导通交流供电回路前，从状态 X（X=1,2,3，定义在表A.4）到状态 X' 时或在状态 X' 期间至少进行一次。当检测到 PWM 信号的低电平状态在表A.4规定的电压范围内时，则判断控制导引电路上存在二极管 D1 且连接的是电动汽车或电动汽车模拟器。

    防反灌二极管（直流充电，附录C / §11）¶

    • D1 / D —— 防反灌电流二极管，可采用其他措施替代（附录C 图C.1/C.2 符号定义）
    • 二极管 D1 适用于预充电时防止反向电流，可集成在充电机中
    • 车辆内部控制导引电路二极管 D1（选配），适用于与欧美充电机充电兼容的电动汽车
    • 启动电流限制（C.7.5）：充电机应具备启动电流限制功能，采用防反灌二极管和旁路预充电路两种方案之一
    • 防反灌二极管方案：充电机检测到电池电压正常后，将输出电压调整到低于当前电池侧电压 1V~10V DC，再闭合 C1 和 C2 导通直流供电回路
    • 绝缘阻抗要求（C.7.8.1）：在接收到充电电流 ≥1A 之前，充电机直流供电回路中从防反二极管到车辆插头处 DC+ 与 DC- 之间的阻抗应符合要求（X电容 ≤1μF 等）
    • 保护配置（§11 开关部件防护）：每条直流供电回路应配置防反灌二极管，二极管应安装在开关部件和每个车辆插头的输出端子之间

    二极管压降 Vd1¶

    检测点2的电压会受到二极管压降的影响，图中 Vd1 为二极管压降（图A.5/A.6/A.7 交流充电连接控制时序图注 a）。等效二极管压降 Vd1 同时是 GB 44263 直流充电异常保护测试的引用参数（见 concepts/standard-gb-44263 §8.2）。
