    IEC 62752:2024 — IC-CPD（随车充）标准¶

    类型: concept 创建时间: 2026-07-23 最后更新: 2026-07-30 来源: IEC 62752:2024 全文

    摘要¶

    IEC 62752:2024（Edition 2.0）是国际电工委员会发布的 IC-CPD（In-Cable Control and Protection Device，车载线内控制保护装置） 标准，适用于电动汽车 Mode 2 充电模式（便携式充电）。IC-CPD 即俗称的"随车充"，集成了剩余电流保护（RCD）、控制导引（Control Pilot）和开关器件于一体。本标准第2版替代了2016年第1版及2018年修正案1，新增了家用插头强制温度控制装置、EMC要求协调等重大技术变更。

    第2版主要技术变更¶

    与第1版（2016+Am1:2018）相比，Edition 2.0 的重大变更：

    1. §8.3.1 修订：强制要求家用插头配备温度控制装置，检测载流部件温度，达到 70°C 时 10秒内断电

      注：英国和爱尔兰（采用 BS 1363-1 插头，最大充电电流 13A）不强制要求插头温度监控装置（标准 NOTE 3）。

    2. 新增 §9.36：温度控制装置验证测试（60°C 起以 5K/h 速率升温至 70°C 断电）
    3. EMC 要求协调：与 IEC 61543:2022 和 IEC 61851-21-2 新版保持一致
    4. 测试和要求全面改进：通用技术改进

    适用范围（§1 Scope）¶

    • 适用产品：IC-CPD（便携式车载线内控制保护装置），用于 Mode 2 充电
    • 功能：同时执行剩余电流检测、比较剩余电流值与动作值、超过时断开被保护电路
    • 电压范围：单相电路 ≤250V，多相电路 ≤480V
    • 电流范围：最大额定电流 32A
    • 频率：AC 仅限，优选 50Hz / 60Hz / 50/60Hz
    • 不适用：双向或反向功率传输（V2G/V2H）
    • IAn 限值：≤30mA，为下游电路提供附加保护（因上游安装可能无 ≤30mA RCD）

    IC-CPD 组成¶

    1. 插头（Plug）：连接固定安装的插座
    2. 功能盒（Function Box）：包含控制和保护功能的一个或多个子组件
    3. 电缆：插头与功能盒之间（可选）、功能盒与车辆连接器之间（可选）
    4. 车辆连接器（Vehicle Connector）：连接电动汽车

    术语定义要点（§3）¶

    3.3 剩余电流相关术语¶

    • IAn（额定剩余动作电流）：IC-CPD 在规定条件下应动作的剩余电流值
    • IAno（额定剩余不动作电流）：IC-CPD 在规定条件下不动作的剩余电流值
    • Ux：IC-CPD 执行其声明功能的线电压极限值
    • I²t（焦耳积分）：电流平方在给定时间间隔内的积分

    3.3.7 控制功能术语¶

    • 系统状态（System State）：充电过程中不同状态，依据 IEC 61851-1:2017 Annex A（如：已连接、准备充电、充电中）
    • 控制导引导体（Control Pilot Conductor）：电缆中的绝缘导体，与保护导体一起构成控制导引电路
    • 控制导引功能（Control Pilot Function）：监控和调节 EV 与功能盒之间的交互

    3.4 测试术语¶

    • Type test（型式试验）：验证设计满足特定要求的试验
    • Routine test（例行试验）：制造期间/后对每个器件进行的试验
    • Self-test（自检）：自动发起的验证 IC-CPD 检测剩余电流能力的程序

    3.5 构造术语¶

    • Function Box（功能盒）：集成控制功能和/或安全功能的适当外壳，是 IC-CPD 的一部分
    • Class I equipment（I类设备）：基本绝缘+保护接地作为故障保护

    分类（§4 Classification）¶

    4.1 按供电方式¶

    分类 说明
    LNSE / LNE 单相+中性线供电
    LLSE / LLE 两相供电
    LLLNSE / LLLNE 三相+中性线供电

    4.2 按构造¶

    分类 说明
    4.2.2 功能盒分离型 RCD功能、开关器件和控制导引集成在插头与车辆连接器之间的功能盒中
    4.2.3 模块化型 a) RCD+开关集成在插头中，控制导引集成在独立功能盒中
    4.2.3 模块化型 b) RCD+开关集成在插头中，控制导引集成在车辆连接器中

    4.3 按电缆连接方式¶

    • 4.3.2 不可拆型（Non-rewirable）：出厂后电缆不可更换
    • 4.3.3 厂家接线型（Manufacturer-wired）：需特殊工具才能拆卸
    • 4.3.4 可插拔型（Pluggable）：至少包含一组互连接头+插座组合

    4.4 按保护导体路径¶

    • 4.4.2 带开关保护导体（Switched PE）：PE 有开关触点
    • 4.4.3 不带开关保护导体（Non-switched PE）：PE 无开关触点

    4.5 按上游保护导体可用性验证¶

    • 4.5.2 有验证：能检测插座上游 PE 的存在和连续性（IT 系统可能不适用）
    • 4.5.3 无验证：不检测上游 PE（适用于 IT 系统）

    4.6 按使用方式¶

    • 4.6.1 便携式（Portable）
    • 4.6.2 壁挂式（Wall mounting）
    • 4.6.3 便携+壁挂式

    特性参数（§5 Characteristics）¶

    Ui（额定绝缘电压） 介电试验电压和爬电距离参考
    In（额定电流） 持续负载电流，最大 32A
    IAn（额定剩余动作电流） 标准值：6/10/15/20/30 mA

    Im（额定通断容量） 最小值 100A
    Iam（额定剩余通断容量） 最小值 100A
    Inc（额定条件短路电流） 标准值 1500A
    Iac（额定条件剩余短路电流） 标准值 1500A

    非动作过电流¶

    • 标准最小非动作过电流值：4×In

    Table 5 — 标准运行条件： | 影响量 | 参考值 | 应用范围 | 容差 | |--------|--------|---------|------| | 环境温度 | 23°C | -25°C ~ +40°C | ±5°C | | 海拔 | — | ≤2000m | — | | 相对湿度 | 75%（40°C时最大值） | — | — | | 外部磁场 | — | ≤5倍地磁场 | — | | 频率 | 额定值 | 参考值±5% | ±2% | | 正弦波失真 | — | ≤5% | — |

    存储和运输极端温度：-40°C ~ 85°C

    构造和操作要求（§8）¶

    §8.1 机械设计¶

    • IC-CPD 最小防护等级：IPXXD（IEC 60529）
    • 可插拔互连接头+插座：未连接时 IPXXB
    • 插头到功能盒最大线缆长度：1.7m
    • 功能盒距插头 >0.3m 时须具备碾压能力（§9.32）
    • 建议插头到功能盒线缆至少 250mm

    §8.2 可插拔连接¶

    • 连接状态下：IP55
    • 未连接状态下：IP24（最低）
    • ≥0.1μF 电容断电后1秒内插针电压 ≤60V

    §8.3 构造¶

    §8.3.1 通用要求（⚠️ Edition 2 关键新增）¶

    • 家用插头强制温度控制装置：检测插头载流部件温度
    • 温度达 70°C 时，10秒内断电
    • 温度传感器失效时：充电须停止或无法启动
    • 插头须为不可拆型（non-rewirable）
    • 控制导引控制器在以下情况不得闭合开关：
    • 控制导引控制器内部单一故障
    • 开关器件控制电路单一故障
    • 剩余电流故障后未复位

    ⚠️ 各国限流备注： - 法国：限 8A（或使用 NF C61-314 专用插座时按声明值） - 英国：最大 13A，插头须符合 BS 1363-1 并标注 EV 适用 - 奥地利：16A 插头持续负载 ≤10A - 德国：持续充电电流 ≤10A - 丹麦：长时间持续负载 ≤6A - 挪威：持续充电电流 ≤10A - 意大利：>10A 推荐使用 IEC 60309-2 配件

    §8.3.11 电缆和软线¶

    Table 6 — 最小电缆截面积： | 控制导引信号限制电流 | 最小截面积(mm²) | AWG | |---------------------|-----------------|-----| | ≤13A | 1.5 | 16 | | 13A < I ≤ 20A | 2.5 | 14 | | 20A < I ≤ 32A | 6 | 10 |

    控制导引线最小截面积：0.5mm² / AWG 20 电缆须符合 IEC 60227、IEC 60245 或 IEC 62893-3 系列

    §8.4 电气性能¶

    §8.4.1 保护导体路径¶

    • PE 路径不得串联任何半导体器件
    • 如 PE 带开关触点：须提供 adequate 接触压力

    §8.4.2 接触机制¶

    • 每根相线和中性线（如有）须有开关触点
    • 4.4.2 类型 PE 开关：先于相线闭合，后于相线断开（或同步）
    • 剩余电流动作后：不得自动重合闸，须用户手动复位
    • 须有指示器显示触点状态

    §8.4.3 电气间隙和爬电距离¶

    Table 7 — 最小电气间隙和爬电距离（基于额定电压和材料组别）： - 基本绝缘（带电部件与PE之间）：0.5-4.0mm（间隙）/ 0.75-5.6mm（爬电） - 触点断开位置间：0.5-4.0mm（间隙）/ 1.05-7.2mm（爬电） - 双重/加强绝缘：试验电压 ×1.6 - 材料 CTI 分组：Group I (≥600V) / Group II (400-600V) / Group IIIa (175-400V) - 海拔修正：3000m ×1.14，4000m ×1.29

    §8.5 电击保护¶

    • 功能盒防护等级：IP55（最低）
    • 浸水测试：功能盒上部置于水下 5cm（IEC 60529 14.2.7）
    • 浸水后：1.25 IAn 脱扣，IAno 不脱扣

    §8.7 温升¶

    Table 8 — 温升限值： | 部件 | 温升限值(K) | |------|------------| | 端子/接线端 | 50 | | 可触及金属部件 | 30 | | 可触及非金属部件 | 50 |

    §8.8 操作特性¶

    • AC 剩余电流：按 Table 2 分断时间
    • DC 分量剩余电流：按 Table 2 + DC 分量验证
    • 平滑 DC 剩余电流：检测 ≤6mA，超过时按 Table 3 分断
    • 复合剩余电流：须检测和分断
    • 脉动 DC（两相供电）：稳态增加 3.5-7mA 须动作
    • 脉动 DC（三相供电）：稳态增加 3.1-6.2mA 须动作
    • 剩余电流动作后：禁止自动重合，须用户交互后自检再充电

    测试要求（§9 Tests）¶

    §9.1 总则¶

    • 型式试验：34项（Table 9，条款 9.3–9.36），分测试序列进行（Annex A）
    • 例行试验：每个器件均须进行（Annex B）
    • 测试条件：20-25°C，额定电压，额定频率±5%
    • 安全相关嵌入式软件版本须在所有型式试验中一致

    §9.5 介电性能试验¶

    • 湿度预处理：91-95% RH，48h，20-30°C
    • 绝缘电阻：≥2MΩ（断开触点间）/ ≥5MΩ（其他测量点）
    • 介电强度：2000V（a-d项）/ 2500V（e项），45-65Hz
    • 冲击耐受电压：2.5kV Uimp（Table 10），5正5负脉冲

    §9.7 操作特性验证¶

    • AC 剩余电流试验（§9.7.2）
    • DC 分量剩余电流试验（§9.7.3）
    • 复合剩余电流试验（§9.7.4）
    • 平滑 DC 剩余电流试验（§9.7.5）
    • 误接线和供电故障试验（§9.7.6）
    • PE 接触行为验证（§9.7.7）
    • PE 与 EV 连接验证（§9.7.8）
    • PE 持续电流验证（§9.7.9）：≤1mA RMS at 1.1 Ue

    §9.9 短路试验¶

    • 功率因数：0.93-0.98
    • 工频恢复电压：105% 额定电压
    • 操作序列：CO - t(3min) - CO - t - CO
    • Table 17 — 最小 I²t 和 Ip 值（按 Inc/Iac 和额定电流分级）
    • 试验后须满足：1.25 IAn 脱扣、PE 路径连续性、介电强度（1000V）

    §9.25 EMC 试验¶

    Table 20 — EMC 抗扰度试验： | 试验项目 | 基础标准 | 测试参数 | 性能判据 | |---------|---------|---------|---------| | 电压暂降 | IEC 61000-4-11 | 0% U/1周期, 70% U/25-30周期 | C | | 电压中断 | IEC 61000-4-11 | 0% U/250-300周期 | C | | 传导干扰 | IEC 61000-4-6 | 0.15-80MHz, Z=150Ω, 10V | A | | 快速瞬变 | IEC 61000-4-4 | 供电侧4kV, 负载侧2kV | B | | 浪涌(T5a) | IEC 61000-4-5 | 共模4kV, 差模2kV | B | | 浪涌(T5b) | IEC 61000-4-5 | 共模2/1/0.5kV, 差模1/0.5kV | C | | 辐射场 | IEC 61000-4-3 | 80MHz-1GHz 10V/m, 1.4-6GHz 3V/m | A | | 传导共模 | IEC 61000-4-16 | 0-150kHz, Level 3 | A | | 静电放电 | IEC 61000-4-2 | ±8kV 空气, ±6kV 接触 | C |

    发射要求：符合 CISPR 14-1

    §9.32 车辆碾压试验¶

    • 5,000N ± 250N：汽车轮胎 P225/75R15，2.2bar，8km/h
    • 11,000N ± 550N：汽车轮胎按额定气压
    • 5000N 后：无严重破裂，须通过介电试验
    • 11000N 后：须合规或已损坏至不可功能

    §9.33 低温存储试验¶

    • -40°C，24h（非运行状态）
    • 恢复室温后：1.0 IAn 脱扣

    §9.34 振动和冲击试验¶

    • 随机振动：2G RMS，IEC 60068-2-64
    • 冲击：10次，半正弦波，100m/s²，16ms
    • 试验后：1.25 IAn 脱扣，电击保护不受影响

    §9.36 温度控制装置验证（⚠️ Edition 2 新增）¶

    • 测试序列1：控制导引 B→C 状态闭合触点，试验箱 60°C 起以 5K/h 升温，载流部件达 70°C 时断电
    • 测试序列2：温度传感器失效/断开，充电须停止或无法启动
    • 同样适用于 ISO 15118 通信模式
