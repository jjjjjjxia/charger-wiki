# 充电模式 (Charging Modes 1-4)

> **类型**: concept
> **创建时间**: 2026-07-22
> **最后更新**: 2026-07-22
> **来源**: [[raw/1_IEC 61851-1-2017.pdf]]
> **标签**: #充电模式 #IEC61851 #交流充电

## 摘要

IEC 61851-1 定义了四种电动汽车充电模式（Mode 1-4），按连接方式和保护方式区分。交流充电桩主要涉及 Mode 1/2/3，Mode 4 为直流充电。欧标交流充电桩产品认证的核心模式为 **Mode 3**（永久连接、带控制导引）。

## 详情

### 四种充电模式对比

| 模式 | 连接方式 | 控制导引 | 额定限值 | 典型场景 |
|------|---------|---------|---------|---------|
| **Mode 1** | 标准插座，无辅助触点 | 无 | 16A / 250V AC 单相；16A / 480V AC 三相 | 基础充电（部分国家禁止） |
| **Mode 2** | 标准插座 + 在线控制保护装置 | 有（插头与 EV 之间） | 32A / 250V AC 单相；32A / 480V AC 三相 | 便携式充电 |
| **Mode 3** | **永久连接**的 AC 供电设备 | 有（延伸至 EV） | 无固定限值（由设备额定值决定） | **交流充电桩主力模式** |
| **Mode 4** | DC 供电设备（永久或插头连接） | 有（延伸至 EV） | DC 输出 | 直流快充 |

### Mode 1 — 基础连接

- EV 通过电缆和插头连接标准 AC 插座，**无**辅助导引或辅助触点
- 限值：16A / 250V AC（单相），16A / 480V AC（三相）
- 须提供保护接地导体
- **国家限制**：US、IL、UK 禁止；IT 公共区域禁止；CA 须带漏电保护

### Mode 2 — 便携式带保护

- EV 连接标准 AC 插座，插头与 EV 之间集成**控制导引功能**和**电击保护系统**
- 限值：32A / 250V AC（单相），32A / 480V AC（三相）
- 须提供保护接地导体
- 壁挂/抗冲击外壳设备须符合 IEC 62752（IC-CPD）
- **国家限制**：US/CA 限 250V；IT 公共区域禁止；CH 限 16A/250V

### Mode 3 — 交流桩主力模式 ⭐

- EV 连接**永久连接**的 AC 供电设备，控制导引功能从供电设备延伸至 EV
- 须提供保护接地导体至 EV 插座和/或车辆连接器
- **这是欧标交流充电桩产品认证的核心模式**
- Case B（供电设备 + 可拆卸电缆）和 Case C（供电设备含固定电缆）为常见配置

### Mode 4 — 直流充电

- 利用 DC 供电设备连接 EV，控制导引从 DC 设备延伸至 EV
- 可永久连接或插头连接
- 须提供保护接地/保护导体
- DC 设备附加要求见 IEC 61851-23

### Mode 2/3/4 强制功能

所有 Mode 2、3、4 设备须提供以下控制导引功能：
1. **保护导体连续性检查** — 持续监测
2. **EV 连接验证** — 确认 EV 正确连接
3. **供电 energization** — 通电至 EV
4. **供电 de-energization** — 断电
5. **最大允许电流控制** — 限制充电电流

### 控制导引 (Control Pilot)

- 通过 PWM 信号实现（Annex A，规范性）
- 充电站与 EV 之间的状态机交互（State A → B → C → D 等）
- 详见 [[concepts/standard-iec-61851-1]] Annex A

## 国标 GB/T 18487.1-2023 充电模式

> 📖 以下内容来源：[[raw/国标/GB_T 18487.1-2023 电动汽车传导充电系统　第1部分：通用要求_unlocked.pdf]] §5.1

国标 GB/T 18487.1-2023 同样定义 Mode 1-4，但与 IEC 存在关键差异：

| 模式 | 国标要求 | 与 IEC 差异 |
|------|---------|------------|
| **Mode 1** | ⛔ **不应使用**（全国统一禁止） | IEC 为部分国家限制，国标统一禁止 |
| **Mode 2** | 单相交流；10A插座≤8A，GB/T 11918插座≤32A；须IC-CPD | 基本一致，电流限制更具体 |
| **Mode 3** | 永久连接；单相≤32A，三相>32A须连接方式C；须RCD | 基本一致 |
| **Mode 4** | 直流；永久连接或标准插头/交流车辆插座；支持V2G | 新增连接方式D/E、V2G功能 |

### 国标连接方式

| 连接方式 | 描述 |
|---------|------|
| A | 电缆永久连接供电设备，可拆卸端连 EV |
| B | 电缆两端可拆卸（供电设备 + EV） |
| C | 电缆永久连接供电设备，含车辆插头 |
| **D** | 新增（GB/T 20234.4 接口） |
| **E** | 新增（GB/T 20234.4 接口） |

### 国标 Mode 3/4 强制功能（§5.2.1）

1. 保护接地导体连续性持续监测
2. EV 与供电设备正确连接确认
3. 供电控制功能
4. 供电设备断电控制功能
5. 允许的可用最大电流
6. **EV 充电唤醒功能**（新增）

> ⚠️ 国标新增"充电唤醒功能"为 IEC 所无。详见 [[concepts/standard-gb-t-18487-1]] §5.2.1.7。
