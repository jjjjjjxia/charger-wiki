# IEC 61851-1:2017 — 电动汽车传导充电系统 通用要求

> **类型**: concept (standard)
> **创建时间**: 2026-07-22
> **最后更新**: 2026-07-22
> **来源**: [[raw/1_IEC 61851-1-2017.pdf]]
> **标签**: #IEC61851 #安规标准 #欧标 #交流充电

## 摘要

IEC 61851-1:2017 是电动汽车传导充电系统的核心国际安规标准（第3版），规定了 EV 供电设备的通用要求，涵盖充电模式定义、电气安全、结构要求和测试方法。欧标交流充电桩的 CE/CB 认证均以此标准为安规依据，是 EN 61851-1 的上游 IEC 标准。

### 适用范围 (Scope)

适用于 **EV 供电设备**（充电桩）的充电，额定参数：
- 额定供电电压：最高 **1000V AC** 或 **1500V DC**
- 额定输出电压：最高 **1000V AC** 或 **1500V DC**

涵盖三个方面：
1. EV 供电设备的特性和运行条件
2. EV 供电设备与 EV 之间的连接规范
3. EV 供电设备的电气安全要求

**不适用于**：维护安全、无轨电车/轨道车辆/工业车辆、EV 车载设备、EMC（车载端，归 IEC 61851-21-1）、RESS 离车充电。

> EMC 要求预计由 IEC 61851-21-2 覆盖；双向能量传输要求尚在考虑中，未纳入本版。

### 关键术语定义（§3）

标准定义了约 50 个术语，分为 4 大类：

#### 3.1 电动供电设备

| 术语 | 定义 |
|------|------|
| EV supply equipment | 从固定电气装置或供电网络向 EV 供电的设备或组合设备 |
| AC/DC EV supply equipment | 分别向 EV 供交流/直流电的设备 |
| EV charging station | 连接到供电网络的 EV 供电设备的固定部分 |
| EV charging system | 包含 EV 供电设备和 EV 端所需功能的完整系统 |
| charging mode | EV 连接到供电网络进行充电的连接方法（Mode 1-4） |

#### 3.1 连接方式（Case A/B/C）

| 方式 | 定义 | 电缆归属 |
|------|------|---------|
| **Case A** | 电缆永久连接到 EV | 电缆属于车辆 |
| **Case B** | 电缆两端均可拆卸 | 电缆独立于车辆和充电站 |
| **Case C** | 电缆和车辆连接器永久连接到充电站 | 电缆属于充电站 |

#### 3.2 绝缘相关

| 术语 | 定义 | 来源 |
|------|------|------|
| basic insulation | 提供基本保护的带电部分绝缘 | IEC 60050-826 |
| supplementary insulation | 基本绝缘之外独立施加的故障保护绝缘 | IEC 60050-826 |
| double insulation | 基本绝缘 + 附加绝缘 | IEC 60050-826 |
| reinforced insulation | 等同于双重绝缘的电击保护等级 | IEC 60050-195 |
| fault protection | 单一故障条件下的电击保护 | IEC 60050-195 |
| hazardous-live-part | 特定条件下可造成有害电击的带电部分 | IEC 60050-195 |

#### 3.3 功能相关

| 术语 | 定义 |
|------|------|
| control pilot conductor | 电缆组件中的绝缘导体，与保护导体共同构成控制导引电路 |
| control pilot circuit | EV 与供电设备之间传输信号或通信的电路 |
| proximity detection | 检测车辆连接器是否正确插入的装置 |

### 防触电保护详细要求（§8）

#### §8.2 存储能量

| 场景 | 断电后时间 | 限值 | 测试方法 |
|------|----------|------|---------|
| 插头连接设备拔出 | **1 秒** | 接触件间电压 ≤ **60V DC** 或存储电荷 ≤ **50μC** | IEC 60950-1:2005 §2.1.1.5 |
| 永久连接设备断电 | **5 秒** | 电压 ≤ **60V DC** 或存储能量 ≤ **0.2J** | IEC 60950-1:2005 §2.1.1.7 |

#### §8.3 故障保护

依据 IEC 60364-4-41，采用以下一种或多种保护措施：
- **自动切断电源**
- **双重或加强绝缘**
- **电气隔离**（限单台设备使用）
- **特低压（SELV/PELV）**

> 电气隔离须为每辆 EV 提供独立的电气隔离电路。

#### §8.4 保护导体

- Mode 1/2/3：须提供 AC 供电输入接地端子到 EV 之间的保护接地导体
- Mode 4：提供接地导体或基于电气隔离的保护导体
- Mode 3/4 永久连接设备：保护接地导体**不得被开关切断**
- 保护导体截面和额定值须符合 IEC TS 61439-7
- ⚠️ CA/US/JP：保护导体尺寸由各国国家法规确定

#### §8.5 残余电流保护器（RCD）

| 要求 | 参数 |
|------|------|
| 额定剩余动作电流 | **≤ 30 mA** |
| RCD 类型 | 至少 **Type A** |
| DC 故障电流保护 | Type B RCD，或 Type A + DC >6mA 断开装置 |
| 适用标准 | IEC 61008-1 / IEC 61009-1 / IEC 60947-2 / IEC 62423 |
| 断开方式 | 断开所有带电导体 |

> 多连接点同时使用时须各自独立保护；不可同时使用的连接点可共用保护装置。

### 电缆组件要求（§11）

#### §11.2 电气额定值

- Case C：电缆组件的电压和电流额定值须与供电设备匹配
- 电流编码（Annex B / IEC 62196-2）：最大电流编码值须与电缆组件额定电流一致
- Mode 3 Case B 电缆：最小耐受 I²t 值 ≥ **75,000 A²s**

> ⚠️ US：须使用 EV/EVJ 系列电缆；JP：须使用 VCT 等电缆类型

#### §11.3 介电耐受

电缆组件介电耐受特性须符合 §12.7 对供电设备的要求：
- Class I：带电部分与地之间，Class I 测试电压
- Class II：带电部分与可触及导电部分之间，Class II 测试电压

#### §11.4 结构要求

- 电缆组件**不得作为延长线使用**（插头和连接器设计为不匹配）
- 电缆绝缘须耐磨，在供电设备分类要求的全部温度范围内保持柔韧性
- 可包含一根或多根电缆，可置于软管、导管或线槽中

#### §11.5 电缆尺寸

- 最大电缆长度须符合各国法规
- US：不超过 **7.5m**（除非配备电缆管理系统）
- CH：不超过 **5m**（除非配备电缆管理系统）

#### §11.6 应力释放

车辆连接器、EV 插头或标准插头中的电缆应力释放须符合相关产品标准（IEC 62196-1、IEC 60309-1、IEC 60884-1）。Case C 供电设备端的应力释放须符合 IEC 62196-1。

#### §11.7 电缆管理和存储

- Case C 供电设备须提供车辆连接器存储装置
- 存储时连接器最低点距地面 **0.5m ~ 1.5m**
- 电缆超过 7.5m 时须配备电缆管理系统，空闲时自由电缆长度不超过 7.5m
- 须防止存储位置电缆过热

### 结构要求与测试 — 补充章节（§12）

> IP 防护等级、绝缘电阻、接触电流、介电耐压、温升、湿热测试、低温测试详见 [[concepts/safety-tests-iec-61851]]。

#### §12.2 机械开关器件特性

| 器件类型 | 适用标准 | AC 使用类别 | DC 使用类别 |
|---------|---------|------------|------------|
| 开关/隔离开关 | IEC 60947-3 | ≥ AC-22A | ≥ DC-21A |
| 接触器 | IEC 60947-4-1 | ≥ AC-1 | ≥ DC-1 |
| 断路器 | IEC 60898-1 / IEC 60947-2 / IEC 61009-1 | — | — |
| 继电器（主电流路径） | IEC 61810-1 | ≥ 50,000 次循环，触点类别 CC2 | — |

**§12.2.6 涌入电流（Inrush current）**：
- AC EV 供电设备须承受 ISO 17409:2015 §8.2.2 规定的涌入电流
- 接触器闭合时峰值电压处：**230A 峰值**，持续 **100μs**
- 随后 1 秒内：**30A (rms)**
- 保护器件不得因涌入电流而脱扣

**§12.2.7 直流剩余电流监测装置（RDC-MD）**：由未来 IEC 62955 覆盖。

#### §12.3 电气间隙和爬电距离

依据 IEC 60664-1，过电压类别要求：

| 连接方式 | 过电压类别 |
|---------|-----------|
| 直接连接公共 AC 电网 | **类别 IV** |
| 永久连接 | **类别 III** |
| Case C 插座/车辆连接器 | 类别 II |
| 插头电缆连接 | **类别 II** |

> 更高过电压类别条件下使用的设备须包含适当的过电压保护器件。

#### §12.11 机械强度

- **Mode 2 EV 供电设备**：外壳最低防机械冲击等级 **IK08**（依据 IEC 62262）
- 测试后判定：IP 等级不降低、无部件松动/脱落/变形、安全功能不受损、应力释放要求仍满足、爬电距离和电气间隙不低于最小值、无火灾或电击风险增加

### 过载和短路保护（§13）

#### §13.1 总则

- 可同时使用的多连接点须各有独立保护
- 不可同时使用的连接点可共用保护（共用器件额定值 ≤ 最低连接点额定值）
- 过电流保护器件须符合 IEC 60947-2 / IEC 60947-6-2 / IEC 61009-1 / IEC 60898 系列 / IEC 60269 系列

#### §13.2 电缆组件过载保护

- Mode 2/3 供电设备须为所有预定电缆导体尺寸提供过载保护（除非上游供电网络已提供）
- 非断路器/熔断器方式：电流超过电缆额定值 **1.3 倍**时须在 **1 分钟内**脱扣

#### §13.3 充电电缆短路保护

| 位置 | I²t 限值 |
|------|---------|
| Mode 3 充电站 EV 插座处 | ≤ **75,000 A²s** |
| Mode 3 Case C 车辆连接器处 | ≤ **80,000 A²s** |

> 80,000 A²s 值与 ISO 17409:2015 一致。

#### §14 自动重合闸

- 自动/远程重合闸仅在**插座未插合**时允许（须由供电设备检测）
- Case C 供电设备**不得提供**自动或远程重合闸
- ⚠️ DK/UK/FR/CH：不允许保护装置自动重合闸

### 标志和说明（§16）

#### §16.1 安装手册（充电站）

须包含：
- 分类信息（Clause 5）
- 接口特性（IEC TS 61439-7:2014 Clause 5）
- 接线说明
- 内置保护器件的类型和额定值（或外部保护器件的安装要求）
- 通风可选功能支持说明（§6.3.2.2）
- 特殊环境条件信息（§5.3）

#### §16.2 用户手册

须说明：
- 允许/不允许使用的适配器或转换器
- **禁止使用延长线**
- 各国使用限制信息

#### §16.3 供电设备标志

**安装和维护时可见可读的标志**：
- a) 制造商名称/商标
- b) 型号/识别号
- c) "Indoor Use Only"（仅室内用时）

**安装时可见可读的标志**：
- d) 制造日期
- e) 电流类型
- f) 频率和相数（AC）
- g) 额定电压（输入/输出）
- h) 额定电流（输入/输出）及确定额定电流的环境温度
- i) 防护等级
- j) 特殊分类/特性/严重环境条件信息

#### §16.4 Case B 电缆组件标志

须标志：制造商名称/商标、型号、额定电压、额定电流、相数、防护等级

#### §16.5 标志耐久性测试

- 模压/冲压/雕刻标志免测
- 其他标志：用手持水浸布擦拭 **15 秒**，再用石油醚浸布擦拭 **15 秒**
- 测试后标志须清晰可读，标牌不得轻易移除或卷边

### 与认证的关系

- **CE 认证**：欧盟将 IEC 61851-1 转化为 EN 61851-1，作为 CE 安规评估依据
- **CB 认证**：以 IEC 61851-1 为测试依据，出具 CB 测试报告
- **多国转证**：CB 报告可支撑日韩澳等国的本地化认证
