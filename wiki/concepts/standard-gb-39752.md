# GB 39752-2024 电动汽车供电设备安全要求

## 摘要

GB 39752-2024 是**强制性国家标准**（注意：GB 非 GB/T），规定了电动汽车供电设备的安全要素要求和试验方法。代替 GB/T 39752-2021（由推荐性升级为强制性），2024-07-24 发布，**2025-08-01 实施**。适用于额定输出电压 1000V AC 或 1500V DC 及以下的模式 2/3/4 供电设备。与 [[concepts/standard-gb-44263]] 配套使用——GB 39752 管"设备安全"，GB 44263 管"系统安全"。

### 适用范围

- 额定输出电压 **1000V AC 或 1500V DC 及以下**的各类型供电设备
- 包括**模式 2、模式 3、模式 4** 的供电设备
- **不涉及**：放电功能供电设备、自动充电、顶部接触式充电

### 核心安全要素要求（第5章）

#### 5.2.6 防护等级

| 使用场景 | 防护等级要求 |
|---------|------------|
| **室外**使用 | ≥ **IP54** |
| **室内**使用 | ≥ **IP32** |
| 模式 2 功能盒部件 | ≥ **IP55**（且符合 GB/T 41589-2022 中 8.5.3） |

> ⚠️ **与 IEC 61851-1 差异**：IEC 要求室内 ≥ IP41、室外 ≥ IP44。国标室外更高（IP54 vs IP44），但室内防水要求更高（IP32 的"3"防尘低于 IP41 的"4"，但"2"防滴 vs"1"防垂直滴水）。详见 [[concepts/comparison-gb-vs-iec-safety]]。

#### 5.3.1 决定性电压等级（DVC）

| DVC 等级 | AC 有效值 | AC 峰值 | DC | 可触摸性 |
|---------|----------|---------|-----|---------|
| A | 30V | 42.4V | 60V | **可触摸** |
| B | 50V | 71V | 120V | 不可触摸 |
| C | 1000V | 4500V | 1500V | 不可触摸 |

#### 5.3.3 剩余电流保护

**交流供电设备**——每个充电接口配备独立 RCD，额定剩余动作电流 **IΔn ≤ 30mA**，须满足以下之一：
- a) A 型 + 6mA 及以上平滑直流剩余电流保护
- b) A 型 + 6mA 及以上平滑直流监测保护装置配合
- c) B 型（当前级供电回路配 B 型或未装 RCD 时）

**直流供电设备**——交流侧主回路须具备上述交流保护功能，或采用双重绝缘/加强绝缘等加强电气防护。

#### 5.3.5 电气间隙和爬电距离

过电压类别：
- 直接连交流供电网（电源部分）：最小过电压类别 **Ⅳ**
- 直接连直流供电网：最小过电压类别 **Ⅱ**
- 永久连交流供电网：最小过电压类别 **Ⅲ**（供电插座/连接方式C车辆插头为 Ⅱ）
- 标准插头电缆连接：最小过电压类别 **Ⅱ**

#### 5.3.6 接触电流

符合 GB/T 18487.1-2023 中 12.1 的要求。

#### 5.3.7 绝缘电阻

| 测试条件 | 绝缘电阻要求 |
|---------|------------|
| **常态**（各回路间、回路与地） | ≥ **10 MΩ** |
| 交变湿热试验后 30min 内（I 类设备） | R > **1 MΩ** |
| 交变湿热试验后 30min 内（II 类设备） | R > **7 MΩ** |

> ⚠️ **与 IEC 61851-1 差异**：IEC 常态绝缘电阻用 500V DC 测试，Class I > 1MΩ、Class II > 7MΩ（未明确常态 10MΩ 要求）。国标常态要求 **10MΩ 更高**，湿热后两者一致。详见 [[concepts/comparison-gb-vs-iec-safety]]。

#### 5.3.8 介电强度

**工频耐受电压**（表4，历时 1min）：

| 额定绝缘电压 Ui | 交流有效值 | 直流 |
|----------------|----------|------|
| Ui ≤ 60 | 1000 | 1415 |
| 60 < Ui ≤ 300 | 1500 | 2120 |
| 300 < Ui ≤ 690 | 1890 | 2670 |
| 690 < Ui ≤ 800 | 2000 | 2830 |
| 800 < Ui ≤ 1000 | 2200 | 3110 |
| 1000 < Ui ≤ 1500 | 2700 | 3820 |

> 出厂试验允许电压高 10%、时间 1s。

**冲击耐受电压**（表5，1.2/50μs 雷电波，3正3负）：

| 系统标称电压 | 冲击耐压 |
|------------|---------|
| ≤50 AC / 71 DC | 500 |
| 100 AC / 141 DC | 800 |
| 150 AC / 213 DC | 1500 |
| 300 AC / 424 DC | 2500 |
| 600 AC / 849 DC | 4000 |
| 1000 AC / 1500 DC | 6000 |

#### 5.4 能量与保护

- 输出过电压/过电流保护：引用 [[concepts/standard-gb-44263]] 对应条款
- 短路保护：交流引用 GB 44263 中 7.1.6，直流引用 8.1.2
- 过温保护：交流引用 GB 44263 中 6.2.1，直流引用 6.2.2
- 负载突降保护（直流）：引用 GB 44263 中 8.2.9
- 防逆流功能（直流）：输出加二极管等，防蓄电池倒灌
- 粘连保护：接触器粘连检测
- 门禁保护：门打开露出带电部分，1s 内须符合 DVC 等级 A
- 绝缘保护（直流）：引用 GB 44263 中 8.1.5

#### 5.6 机械强度

- 模式 2：IC-CPD 耐车辆碾压（GB/T 41589-2022 中 8.1）、耐机械冲击/撞击（8.11）、耐振动冲击（8.25）
- 模式 3/4：机械强度要求（更改自 2021 版）

#### 5.6.2 机械强度详细要求

| 设备类型 | 机械强度要求 |
|---------|------------|
| 模式 2（IC-CPD） | 耐车辆碾压、耐机械冲击/撞击、耐振动冲击（均按 GB/T 41589-2022） |
| 模式 3/4 **金属外壳** | ≥ **IK10**（GB/T 20138） |
| 模式 3/4 **非金属外壳** | ≥ **IK08**（GB/T 20138） |

> 液晶屏幕、薄膜按键、装饰性面板、指示灯、锁具等部位除外。

### 过热及着火（§5.5）

#### §5.5.1 危险识别

供电设备正常工作时，应防止以下情况引起的过热：
- 可接触部位超过安全温度
- 部件、零件、绝缘和塑料材料超过特定温度
- 结构和安装表面超过特定温度

#### §5.5.2 允许表面温度

在最大充电电流和环境温度 40°C 条件下：

| 部位 | 金属部分 | 非金属部分 |
|------|---------|----------|
| **手握可接触表面** | ≤ **50°C** | ≤ **60°C** |
| **可触及但不可手握表面** | ≤ **60°C** | ≤ **85°C** |
| **充电电缆表面** | ≤ **77°C**（超过 60°C 须增加高温警示标识） | — |

#### §5.5.3 引燃和火焰蔓延

正常工作和单一故障条件下，须通过适当材料和结构限制引燃和火焰蔓延：
- 使用阻燃材料、绝缘或提供足够阻隔
- 限制元器件最高温度或限制电路有效功率

### 电磁兼容（§5.7）

#### §5.7.1 抗扰度要求

供电设备的抗扰度试验类别和等级应符合 **GB/T 18487.2** 的要求。

#### §5.7.2 发射要求

供电设备以下端口的骚扰限值须符合 GB/T 18487.2：
- 电源输入端口：传导骚扰限值、谐波电流、电压波动和闪烁
- CPT 端口、信号/控制端口：传导骚扰限值
- 外壳端口：辐射骚扰限值

### 标识与指示（§5.8）

#### §5.8.1 标识

- 产品标识内容符合 GB/T 18487.1-2023 第 17 章要求
- 标识须在正确安装后能从外部直接可见，或在不需要工具即可打开的盖/门后直接可见
- 警示标志须符合 GB 2894 规定的类型、颜色、材质、尺寸和使用要求

#### §5.8.2 指示

供电设备须提供以下一种或两种指示：
- 集成的直接可见/可听指示
- 远程访问电气/电子指示（信号继电器触点、集电极开路输出或通信系统信息发送）

### 附录A：供电设备安装（规范性）

#### §A.1 安装要求

- 安装应便于车辆充电，环境温度满足供电设备正常工作要求
- 安装应牢固可靠，锁紧零件齐全
- 室外落地安装且防护等级低于 IP67 的设备：裸露带电部分离地坪 ≥ **0.2m**（含安装基础/支座）
- 室外或潮湿场所安装：电源接线口须采取密封处理等防水防潮措施

#### §A.2 配电系统

| 回路类型 | RCD 要求 |
|---------|---------|
| **专用供电回路** | A 型 RCD，IΔn ≤ **30mA**（具备加强电气防护可免配） |
| **非专用供电回路** | 每分支 A 型 RCD IΔn ≤ 30mA，或每设备配 30mA RCD；回路始端 RCD IΔn ≤ **300mA** |

- 配电回路须设置短路保护

#### §A.3 配电线路

- 线缆截面选择符合 GB 50217，中性线截面符合 GB 50054
- 场站供配电线路容量小于总负荷时，供电设备须保证充电电流不超过实时可用负载电流

#### §A.4 防火要求

- 建（构）筑物内安装时，构件燃烧性能和耐火极限须符合 GB 50067、GB 50016、GB 55037
- 供电电源进线、分体式设备本体与充电终端间输出线：燃烧性能 ≥ **B2 级**，燃烧滴落物/微粒 ≥ **d1 级**
- 防火与阻止延燃敷设须符合 GB 50217

#### §A.5 接地

| 配电系统 | 接地要求 |
|---------|---------|
| **TN 系统** | 优先与就近建筑/配电设施共用接地装置；无法共用时加装接地装置，PE/PEN 重复接地，接地电阻 ≤ **10Ω** |
| **TT 系统** | 供电回路须装 IΔn ≤ 30mA 的 RCD；外露可导电部分可靠接地，接地电阻 ≤ **500Ω** |

### 环境适应性试验（7.1）

| 试验项目 | 条件 | 持续 |
|---------|------|------|
| 低温 | 室外 **-25°C** / 室内 **-5°C** | 2h |
| 高温 | **+40°C** | 2h |
| 交变湿热 | 40°C，12h+12h 循环 | **2 次循环** |
| 盐雾 | GB/T 2423.17（特殊环境） | — |
| 光老化 | GB/T 16422.2（高辐照环境） | — |

> 湿热试验结束前 2h 进行绝缘电阻和介电强度复试：I 类 ≥ 1MΩ，II 类 ≥ 7MΩ，介电强度按 75% 施加。

### 标准的实施（第8章）— 过渡期

| 对象 | 执行时间 |
|------|---------|
| **新申请型式试验**的供电设备 | 自 **2025-08-01** 起执行 |
| **已获型式试验报告**的供电设备 | 自实施之日起**第13个月**（**2026-08-01**）起执行 |

> ⚠️ 这意味着已有 CCC/CQC 型式试验报告的产品有 **1 年过渡期**，2026-08-01 后必须符合新标。
