# IEC 61851-1 与 IEC 62752 对比分析

> **类型**: comparison
> **创建时间**: 2026-07-23
> **最后更新**: 2026-07-23
> **来源**: [[raw/欧标/桩标准/IEC 61851-1-2017-1.md]], [[raw/欧标/随车充标准/IEC 62752 2024(1).md]]

## 摘要

IEC 61851-1 和 IEC 62752 是欧洲/国际充电桩标准体系中的两个核心标准，但它们的定位不同：IEC 61851-1 是充电系统的**通用基础标准**，覆盖所有充电模式（Mode 1-4）；IEC 62752 是专门针对 **Mode 2 充电（便携式随车充/IC-CPD）** 的产品标准。两者是**互补关系**，IC-CPD 的控制导引功能需符合 IEC 61851-1 的要求。

## 对比总览

| 对比维度 | IEC 61851-1:2017 | IEC 62752:2024 |
|---------|-------------------|-----------------|
| **标准定位** | 充电系统通用基础标准 | IC-CPD 产品专用标准 |
| **适用产品** | 所有EV充电设备（固定式/便携式） | IC-CPD（便携式随车充） |
| **充电模式** | Mode 1/2/3/4（全覆盖） | 仅 Mode 2 |
| **产品类型** | 充电站/充电桩/充电电缆 | 车载线内控制保护装置 |
| **最大电压** | 交流 690V，直流 1500V | 交流 ≤250V（单相）/ ≤480V（多相） |
| **最大电流** | 未限定（按模式不同） | ≤32A |
| **RCD 要求** | Type A RCD（最低要求） | 内置 RCD，IAn ≤30mA |
| **控制导引** | 定义 CP 电路和状态机 | 引用 IEC 61851-1 Annex A |
| **温度控制** | 无特定插头温度要求 | ⚠️ 家用插头强制温度控制（70°C/10s） |
| **机械强度** | IK08（Mode 2/3 便携式） | IK08（壁挂式功能盒） |
| **碾压测试** | 未明确 | 5000N + 11000N |
| **短路 I²t** | 75,000/80,000 A²s | Table 17（按 Inc 分级） |
| **EMC** | 引用 IEC 61851-21 | 引用 IEC 61543 + CISPR 14-1 |
| **自检功能** | 未明确要求 | 强制（每次连接供电/车辆时） |

## 详细对比

### 1. 适用范围

**IEC 61851-1**：
- 覆盖所有充电模式（Mode 1-4）
- Mode 1：无保护电缆连接
- Mode 2：带 IC-CPD 的便携式充电
- Mode 3：固定式充电桩
- Mode 4：直流快充
- 电压：交流 ≤690V，直流 ≤1500V

**IEC 62752**：
- 专门针对 Mode 2 的 IC-CPD
- 电压：单相 ≤250V，多相 ≤480V
- 电流：≤32A
- 不适用于双向/反向功率传输

### 2. 产品定义与构造

**IEC 61851-1** 定义了充电系统的通用架构：
- 充电站（EVSE）包含：供电接口、控制导引、保护装置、连接器
- Case A/B/C 三种连接方式

**IEC 62752** 定义了 IC-CPD 的具体构造：
- 插头 + 功能盒 + 电缆 + 车辆连接器
- 功能盒类型：分离型（4.2.2）和模块化型（4.2.3）
- 电缆连接方式：不可拆型/厂家接线型/可插拔型
- PE 路径：带开关/不带开关
- 使用方式：便携式/壁挂式/两用

### 3. 剩余电流保护

| 项目 | IEC 61851-1 | IEC 62752 |
|------|-------------|-----------|
| RCD 类型 | Type A（最低） | 内置，Type A + DC 6mA 检测 |
| IAn 标准值 | 未限定具体值 | 6/10/15/20/30 mA |
| DC 剩余电流 | 要求保护 | 平滑 DC ≤6mA 检测，超过时按 Table 3 分断 |
| 脉动 DC | 未详细规定 | 两相 3.5-7mA，三相 3.1-6.2mA 须动作 |
| 复合剩余电流 | 未详细规定 | 须检测和分断 |
| 分断时间 | 未限定 | AC: 2IAn→0.04s, DC 6mA→10s |

> ⚠️ **矛盾标注**：IEC 61851-1 仅要求 Type A RCD，而 IEC 62752 要求 IC-CPD 能检测平滑 DC 剩余电流（6mA）和脉动 DC，这实际上比 Type A 更严格（接近 Type B 或 Type A+DC 检测的要求）。

### 4. 控制导引（Control Pilot）

**IEC 61851-1**：
- 定义了完整的 CP 电路和状态机（Annex A）
- 状态 A-F：State A（未连接）→ State B（已连接）→ State C（准备充电）→ State D（充电中）→ State E/F（故障）
- PWM 占空比编码最大充电电流
- 定义了通信协议基础

**IEC 62752**：
- 直接引用 IEC 61851-1:2017 Annex A.2.2
- CP 电路视为 SELV/PELV 电路
- PWM 占空比须指示 IC-CPD 的最大电流
- 支持简化控制导引电路（额定电流 ≥10A，部分国家不允许）
- 支持通信时同样适用 ISO 15118

### 5. 温度保护（⚠️ Edition 2 关键差异）

| 项目 | IEC 61851-1 | IEC 62752 Edition 2 |
|------|-------------|---------------------|
| 插头温度监控 | 未要求 | **强制**：家用插头载流部件温度检测 |
| 断电阈值 | — | **70°C** |
| 断电时间 | — | **10秒内** |
| 传感器失效 | — | 充电须停止或无法启动 |
| 验证测试 | — | §9.36（60°C 起 5K/h 升温） |

### 6. 机械强度与防护

| 项目 | IEC 61851-1 | IEC 62752 |
|------|-------------|-----------|
| IK 等级 | IK08（Mode 2/3 便携式） | IK08（壁挂式功能盒） |
| IP 等级 | IP44（户外，按安装环境） | IP55（功能盒），IP24（未连接插拔件） |
| 碾压测试 | 未明确 | 5000N（轮胎 P225/75R15）+ 11000N |
| 振动测试 | 未明确 | 2G RMS 随机振动 + 10次 100m/s² 冲击 |
| 低温存储 | 未明确 | -40°C / 24h |

### 7. 短路保护

| 项目 | IEC 61851-1 | IEC 62752 |
|------|-------------|-----------|
| I²t 要求 | 75,000 A²s（Mode 2/3）/ 80,000 A²s | Table 17（按 Inc/Iac 和额定电流分级） |
| Inc 标准值 | 未明确 | 1500A |
| 功率因数 | 未明确 | 0.93-0.98 |
| 恢复电压 | 未明确 | 105% 额定电压 |
| SCPD 协调 | 要求但未详细规定 | 详细规定（§9.9.2） |

### 8. 自检功能

| 项目 | IEC 61851-1 | IEC 62752 |
|------|-------------|-----------|
| 自检要求 | 未明确 | **强制**（§8.14） |
| 触发条件 | — | 连接供电时、连接车辆时（10分钟内一次即可） |
| 检测内容 | — | 剩余电流检测和评估功能（不含触点机构） |
| 失败处理 | — | 禁止充电（PWM 信号），指示故障 |
| 触点检测 | — | 自动检测意外闭合触点 |

### 9. EMC 要求

| 项目 | IEC 61851-1 | IEC 62752 |
|------|-------------|-----------|
| 发射 | 引用相关标准 | CISPR 14-1 |
| 抗扰度 | 引用 IEC 61851-21 | 引用 IEC 61543:2022 |
| ESD | 未详细规定 | ±8kV 空气，±6kV 接触 |
| 浪涌 | 未详细规定 | 共模 4kV，差模 2kV |
| 快速瞬变 | 未详细规定 | 供电侧 4kV，负载侧 2kV |
| 辐射场 | 未详细规定 | 80MHz-1GHz 10V/m，1.4-6GHz 3V/m |
| 性能判据 | 未明确 | A/B/C 三级 |

### 10. 特殊环境测试（IEC 62752 独有）

IEC 62752 包含多项 IEC 61851-1 未涉及的便携设备专用测试：
- **化学负载测试**（§9.28）：ISO 16750-5
- **太阳辐射热测试**（§9.29）
- **UV 辐射测试**（§9.30）
- **潮湿盐雾测试**（§9.31）：海洋和海岸环境
- **车辆碾压试验**（§9.32）：5000N + 11000N
- **低温存储试验**（§9.33）：-40°C/24h
- **振动冲击试验**（§9.34）：2G RMS + 100m/s²

## 标准关系图

```
IEC 61851-1（充电系统通用要求）
    │
    ├── Mode 1 ──→ 无 IC-CPD（基本不推荐）
    ├── Mode 2 ──→ IEC 62752（IC-CPD 产品标准）
    │                   ├── 引用 IEC 61851-1 Annex A（控制导引）
    │                   ├── 引用 IEC 60884-1（家用插头）
    │                   ├── 引用 IEC 60309（工业插头）
    │                   ├── 引用 IEC 62196（车辆连接器）
    │                   ├── 引用 IEC 61543（EMC）
    │                   └── 引用 IEC 60529（IP 防护）
    ├── Mode 3 ──→ IEC 61851-1 + IEC 61851-21/22（固定式充电桩）
    └── Mode 4 ──→ IEC 61851-1 + IEC 61851-23/24（直流快充）
```

## 设计建议

1. **Mode 2 产品认证**：IC-CPD 产品须同时符合 IEC 62752（产品要求）和 IEC 61851-1（控制导引要求）
2. **RCD 选型**：IC-CPD 内置 RCD 须支持 DC 6mA 检测，不能仅用 Type A
3. **温度监控**：家用插头版本须设计温度传感器（70°C 断电），Edition 1 产品须升级
4. **碾压设计**：功能盒距插头 >0.3m 时须承受 11000N 碾压
5. **自检功能**：每次连接供电/车辆时自动执行，10分钟间隔
6. **电缆选型**：按 Table 6 选择最小截面积，控制导引线 ≥0.5mm²
7. **PE 持续电流**：≤1mA RMS at 1.1 Ue（设计须考虑）
8. **各国限流**：注意各国国家差异（法国8A、英国13A、德国/奥地利/挪威10A、丹麦6A）
