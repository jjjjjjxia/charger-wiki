# IEC 62955:2018 — RDC-DD 直流剩余电流检测装置标准

> **类型**: concept
> **创建时间**: 2026-07-23
> **最后更新**: 2026-07-23
> **来源**: [[raw/漏电/IEC62955_2018.md]]

## 摘要

IEC 62955:2018 Edition 1.0 规定了电动汽车 **Mode 3 充电**用直流剩余电流检测装置（RDC-DD, Residual Direct Current Detecting Device）的技术要求、测试方法和标志信息。该标准旨在解决传统 Type A/F RCD 无法检测 >6mA 平滑直流剩余电流的盲区问题，确保充电过程人身安全。RDC-DD 分为 RDC-MD（监测装置）和 RDC-PD（保护装置）两大类，涵盖额定电压 ≤440V AC、额定电流 ≤125A、IΔdc=6mA 的产品。

## 适用范围（§1 Scope）

### 适用对象

- **RDC-DD**：电动汽车 Mode 3 充电用直流剩余电流检测装置
- 交流额定电压：≤440V
- 交流额定电流：≤125A
- 额定直流剩余动作电流：IΔdc = **6mA**
- 频率：50Hz / 60Hz / 50-60Hz

### Mode 3 充电的漏电保护问题

电动汽车充电过程中，整流性负载（车载充电机）可能产生平滑直流剩余电流。传统 RCD（Type A）对直流 >6mA 的平滑剩余电流存在检测盲区——直流分量会导致 RCD 铁芯磁化，使其对交流剩余电流的灵敏度下降甚至失效。IEC 62955 定义的 RDC-DD 专门检测此类直流剩余电流，与 RCD 配合使用，构成完整的漏电保护方案。

### 不适用

- Mode 1/Mode 2 充电（IC-CPD 随车充见 [[concepts/standard-iec-62752]]）
- 直流充电（Mode 4）
- 家用及类似用途的常规 RCD（IEC 61008/61009 系列）

## 术语定义（§3）

### 核心术语

| 术语 | 定义 |
|------|------|
| **RDC-DD** (Residual Direct Current Detecting Device) | 直流剩余电流检测装置，用于 Mode 3 充电，检测 ≥6mA 平滑直流剩余电流 |
| **RDC-MD** (RDC Monitoring Device) | RDC 监测装置——检测直流剩余电流并通过信号输出触发外接保护器件动作 |
| **RDC-PD** (RDC Protective Device) | RDC 保护装置——集成 AC/脉动 DC/6mA DC 检测 + 评估 + 机械开关于一体 |
| **RDC-M-unit** | RDC-MD 中的检测单元，不含机械开关 |
| **RDC-M-module** | RDC-MD 中电气耦合型式的检测/监测模块（含 CT 互感器接口） |
| **IΔdc** | 额定直流剩余动作电流 = 6mA |
| **IΔndc** | 额定直流剩余不动作电流 = 0.5 × IΔdc = 3mA |
| **IΔn** | 额定交流剩余动作电流（如 30mA） |
| **RDC-DD 的 RDC-MD** | 由检测/监测单元 + 外接开关/保护器件组成的组合装置 |

### 与传统 RCD 的关系

RDC-DD 是对现有 RCD 标准体系的补充：
- **Type A RCD**（IEC 61008-1/61009-1）：检测 AC + 脉动 DC，但无法检测平滑 DC > 6mA
- **Type B RCD**：可检测平滑 DC，但成本高、体积大
- **RDC-DD**（IEC 62955）：专用于 Mode 3 充电场景，检测 6mA DC，与 Type A RCD 组合使用，成本效益优于 Type B

## 构造要求（§8）

### 8.1 通用要求

RDC-DD 设计应确保在正常使用条件下安全可靠运行。材料和结构应满足电气、机械、热学及防火要求。

### 8.2 材料

- 金属材料应耐腐蚀或经防腐处理
- 绝缘材料应满足耐热、耐燃、耐异常热要求
- 印制电路板（PCB）应符合 IEC 61249 系列

### 8.3 标志耐久性

标志应在正常使用中保持清晰可辨。测试：用布浸水轻擦 15s，再浸汽油轻擦 15s，标志不得模糊脱落。

### 8.4 防护等级

- 基本防护：IP20（仅防触指）
- 实际产品通常 ≥ IP20，与外接保护器件匹配

### 8.5 外部部件

外部操作件（如试验按钮）应满足：
- 绝缘材料制成，或金属件需有双重绝缘
- 操作力正常使用中不会造成松动

### 8.6 端子

- 螺纹端子：可靠连接导体，防松动防扭转
- 无螺纹端子：应符合相关 IEC 标准
- 端子应能夹持规定截面的导体

### 8.7 端子排列

端子排列应便于正确接线，防止误接线。

### 8.8 电气连接

电气连接应可靠，接触电阻低，在温升和短路条件下不松动。

### 8.9 操作件

操作件（手柄、试验按钮）应有清晰的开/关位置标志，操作可靠。

### 8.10 固定件

必要的固定件不得缺失，防止误拆卸。

### 8.11 印制电路板

PCB 应满足：
- 电气间隙和爬电距离符合 Table 6
- 涂覆层（如有）应均匀无针孔

### 8.12 电气间隙和爬电距离

按 **Table 6** 规定，取决于：
- 额定冲击耐受电压 Uimp（2.5kV / 4kV）
- 材料组别（按 CTI 值分组：I ≥600, II 400-599, IIIa 175-399）

| Uimp | 最小电气间隙 | 爬电距离（材料组别 II） |
|------|-----------|-------------------|
| 2.5kV | 1.5mm | 3.0mm |
| 4.0kV | 3.0mm | 5.0-8.0mm |

### 8.13 螺钉、载流部件和连接

螺钉和连接件应能承受正常使用中的机械应力，不松动、不变形。

### 8.14 外部导体端子

端子应能连接标准截面的铜导体，夹持力适中不损伤导体。

### 8.15 外部导体连接系统

如采用插入式或快速连接系统，应确保可靠接触且防误插。

### Table 8 — 温升限值

| 部件 | 温升限值 (K) |
|------|-------------|
| 端子 | 65 |
| 操作件金属外露部分 | 25 |

### 关键测试详解

#### §9.7 介电性能

- 工频耐压：2kV AC（1 min），施加在带电部件与外壳间
- 冲击耐压：按 Uimp 值（2.5kV / 4kV），1.2/50μs 标准冲击波

#### §9.8 温升

- 通以额定电流 In，至稳态
- 端子温升 ≤ 65K，操作件 ≤ 25K，外壳 ≤ 60K
- 测量热电偶法

#### §9.9 动作特性

**直流剩余电流测试（Table 2 限值）：**
- 6mA DC → 分断 ≤ 10s
- 60mA DC → 分断 ≤ 0.3s
- 200mA DC → 分断 ≤ 0.1s

**AC 剩余电流测试（Table 3 限值）：**
- ≤ 30mA AC → 不脱扣（不干扰 RCD）
- 60mA AC → ≤ 0.3s
- 150mA AC → ≤ 0.08s
- 5A AC → ≤ 0.08s

**不动作电流：**
- IΔndc = 3mA DC（0.5×IΔdc）→ 不脱扣

#### §9.10 机械和电气耐久

- 机械耐久：操作 1000 次（不带电）
- 电气耐久：通以 In 操作 1000 次（带载通断）

#### §9.11 短路性能

- 额定条件短路电流 Inc：3000~25000A
- 额定短路通断电流 Im：min(10×In, 500A)
- 测试按 Table 16 的 I²t/Ip 限值和 Table 17 功率因数
- "O-t-CO" 操作序列（分断-延时-合分）

#### §9.12 机械冲击和撞击

- 机械冲击：0.5J 冲击能量，弹簧锤
- 撞击：按 IEC 60068-2-75 弹簧锤测试

#### §9.18 电流浪涌

**§9.18.1 环波电流（0.5μs/100kHz Ring Wave）：**
- 测试电流：200A（8/20μs 波形前半周期）
- 不应误脱扣

**§9.18.2 浪涌电流（8/20μs Surge）：**
- 测试电流：3000A
- 不应误脱扣
- 如脱扣，分断时间 ≥ 0.08s（选择性）

#### §9.19 可靠性

**§9.19.2 气候循环试验（28 次循环）：**
- 每循环 24h：高温高湿 55°C / 93% RH
- 每循环温度交替变化
- 试验后验证动作特性

**§9.19.3 带载运行试验（28 周期）：**
- 40°C 环境温度
- 通以额定电流 In
- 每周期 21h 带载 + 3h 断电
- 试验后验证动作特性

#### §9.20 电子元件老化

- 168h（7天）@ 40°C
- 施加 1.1 × Un（额定电压的 110%）
- 通以额定电流 In
- 老化后验证动作特性

#### §9.21 电磁兼容（EMC）

- 发射：符合 IEC 61000-6-3 或产品族标准
- 抗扰度：符合 IEC 61000-6-2 或产品族标准
- 具体测试项：静电放电(ESD)、射频电磁场、电快速瞬变脉冲(EFT)、浪涌、传导骚扰、辐射骚扰、电压暂降/中断

- 动作特性 (§9.9) 需额外验证 6mA DC 检测功能
- 自由脱扣 (§9.15) 和两极供电 (§9.17) 仍按本标准执行
- 电气耐久、电流浪涌、可靠性、老化、EMC 由 RCD 标准 + 本标准双重覆盖

## 与知识库已有标准的关联

### 与 IEC 61851-1 的关系

[[concepts/standard-iec-61851-1]] 定义了 Mode 3 充电系统通用要求。IEC 61851-1 §4.7（电击保护）要求充电站安装 RCD（Type A/B）或等效剩余电流保护装置。IEC 62955 即为满足这一要求而制定的专用标准——针对 Mode 3 充电场景的直流剩余电流检测。

**关键关系链：**
```
IEC 61851-1 (Mode 3 通用要求)
  └─ §4.7 电击保护 → 要求 RCD 保护
      └─ RCD Type A 盲区 (DC > 6mA) → 需要 RDC-DD 补充
          └─ IEC 62955 (RDC-DD 专用标准)
```

### 与 IEC 62752 的关系

[[concepts/standard-iec-62752]] 是 Mode 2 充电（IC-CPD 随车充）专用标准。两者互补但互不替代：
- IEC 62752 适用 Mode 2（便携式随车充）
- IEC 62955 适用 Mode 3（永久连接充电桩）
- 两者都要求 6mA DC 检测，但测试要求和产品形态不同

> ⚠️ **矛盾标注**：IEC 61851-1:2017 仅要求 Type A RCD（可检测 AC + 脉动 DC），而 IEC 62955:2018 要求 6mA 平滑 DC 检测。后者在直流剩余电流保护上更严格，实际产品设计中须同时满足两者。

### 与国标体系的关系

国标 GB 44263-2024（[[concepts/standard-gb-44263]]）在交流充电安全要求中也提到 RCD ≤30mA + A型/6mA DC/B型。这与 IEC 62955 的 IΔdc=6mA 参数一致，说明国标体系也在跟进 IEC 的 RDC-DD 理念。

## 设计建议

1. **Mode 3 充电桩必须配置 RDC-DD**：仅使用 Type A RCD 无法满足 IEC 62955 的直流剩余电流检测要求，建议 RDC-DD + Type A RCD 组合方案
2. **选择 RDC-PD 还是 RDC-MD**：RDC-PD 集成度高（一体式），安装简便；RDC-MD 灵活，可与已有断路器/RCD 组合，改造成本低
3. **关注分断时间限值**：6mA/10s 看似宽松，但需注意 60mA/0.3s 和 200mA/0.1s 的阶梯式要求
4. **AC 剩余电流不动作**：确保 RDC-DD 不干扰 RCD 对 AC 剩余电流的正常保护功能
5. **可靠性测试周期长**：气候循环 28 次 + 带载运行 28 周期，认证周期需预留足够时间
6. **EMC 兼容性**：充电桩环境存在大量电力电子设备（整流器、逆变器），RDC-DD 的 EMC 抗扰度至关重要
7. **电气耦合型 CT 互感器选型**：Annex N 规定的贯穿导体型需关注导体孔径和安装位置，避免临近导体干扰
