# 全球插头插座型号体系（Type A–O）

> **类型**: concept
> **创建时间**: 2026-07-27
> **最后更新**: 2026-07-27
> **来源**: [[raw/插头标准/多国插头及电压标准.md]]

## 摘要

全球民用电源插头插座共划分为 **15 种标准型号**（Type A 至 Type O），由 IEC 60884-1 体系及各国国家标准定义。不同型号在插脚形状、接地方式、额定电流、电压等级上存在差异。充电桩产品出口不同国家时，需匹配目标市场的插头插座标准（特别是便携式充电器/随车充产品），详见 [[topics/global-plug-lookup]]。

## 15 种插头型号详解

### Type A — 两脚扁型（无接地）

| 属性 | 内容 |
|------|------|
| **形状** | 两根平行扁脚，无接地 |
| **标准** | NEMA 1-15 (US), JIS C 8303 (JP) |
| **额定** | 15A, 125V |
| **主要地区** | 北美、中美洲、日本、中国（部分） |
| **说明** | 美国与日本插头外观相似，但美国零线脚更宽（极性化）；日本两脚等宽。中国同时使用 A 型和 I 型。 |

### Type B — 两脚扁型 + 圆形接地脚

| 属性 | 内容 |
|------|------|
| **形状** | 两根平行扁脚 + 下方圆形接地脚 |
| **标准** | NEMA 5-15P (US), JIS C 8303 (JP) |
| **额定** | 15A, 125V |
| **主要地区** | 北美、中美洲、日本 |
| **说明** | 接地脚较长，插入时先接地后通电。兼容 A 型插头。 |

### Type C — 两脚圆型（无接地）

| 属性 | 内容 |
|------|------|
| **形状** | 两根圆脚（4mm 或 4.8mm），无接地 |
| **标准** | CEE 7/16 (Europlug) |
| **额定** | 2.5A, 250V |
| **主要地区** | 欧洲、亚洲、南美多国（全球最普及的无接地插头） |
| **说明** | 俗称欧标/Europlug，无接地。可插入 E/F/H/J/K/L/N 等带接地插座但无接地保护。是使用国家最多的插头型号。 |

### Type D — 三脚圆型大三角形

| 属性 | 内容 |
|------|------|
| **形状** | 三根大圆脚呈等边三角形排列 |
| **标准** | BS 546 (5A) |
| **额定** | 5A, 250V |
| **主要地区** | 印度、南非、尼泊尔、巴基斯坦等（前英国殖民地） |
| **说明** | 源自旧英国标准 BS 546（5A），三根大圆脚呈三角形。 |

### Type E — 两脚圆型 + 中下方接地孔

| 属性 | 内容 |
|------|------|
| **形状** | 两根圆脚 + 插头面上有一个接地孔 |
| **标准** | CEE 7/6 (插头) / CEE 7/5 (插座) |
| **额定** | 16A, 250V |
| **主要地区** | 法国、比利时、波兰、捷克、斯洛伐克、突尼斯、摩洛哥等 |
| **说明** | 插座上有接地柱，插头对应接地孔。与 F 型不互插（接地方式不同）。 |

### Type F — 两脚圆型 + 两侧接地弹片

| 属性 | 内容 |
|------|------|
| **形状** | 两根圆脚 + 插头两侧弹片接地 |
| **标准** | CEE 7/4 (Schuko) |
| **额定** | 16A, 250V |
| **主要地区** | 德国、西班牙、俄罗斯、荷兰、瑞典、芬兰、挪威等（欧洲最主流） |
| **说明** | 俗称 Schuko（德语 Schutzkontakt），两侧弹片接地，兼容 C 型插头。是欧洲使用最广泛的接地插头。 |

> ⚠️ **矛盾标注：E 型 vs F 型**
> E 型和 F 型插脚尺寸相同（4.8mm 圆脚，19mm 间距），但接地方式完全不同——E 型用正面接地柱，F 型用侧面弹片。两者插座不互插。但 **CEE 7/7 混合插头**同时兼容两种接地方式，在 E 和 F 插座上均可使用，实际产品中非常常见。

### Type G — 三脚方型（英标）

| 属性 | 内容 |
|------|------|
| **形状** | 三根矩形扁脚呈三角形排列 |
| **标准** | BS 1363 |
| **额定** | 13A, 250V |
| **主要地区** | 英国、新加坡、中国香港、马来西亚、沙特、阿联酋等 |
| **说明** | 三脚均为矩形，插头内部通常带保险丝（安全特性）。是前英国殖民地广泛使用的标准。 |

### Type H — 三脚扁三角型（以色列标）

| 属性 | 内容 |
|------|------|
| **形状** | 三根扁平脚呈 Y 形 |
| **标准** | SI 32 |
| **额定** | 16A, 250V |
| **主要地区** | 以色列 |
| **说明** | SI 32，三根扁平脚呈 Y 形。新版以色列插头已改为圆脚但仍称 Type H。 |

### Type I — 八字形三脚（澳标/中国标准）

| 属性 | 内容 |
|------|------|
| **形状** | 两根斜扁脚呈八字形 + 上方接地扁脚 |
| **标准** | AS/NZS 3112 (AU/NZ), GB 2099 (CN) |
| **额定** | 10A, 250V |
| **主要地区** | 中国、澳大利亚、新西兰、阿根廷、中国台湾（部分） |
| **说明** | AS/NZS 3112，两根斜脚 + 上方接地脚。中国同时使用 A 型和 I 型。 |

### Type J — 三脚圆型三角形（瑞士标）

| 属性 | 内容 |
|------|------|
| **形状** | 三根圆脚呈三角形排列（中间偏移） |
| **标准** | SEV 1011 |
| **额定** | 10A, 250V |
| **主要地区** | 瑞士、列支敦士登 |
| **说明** | SEV 1011，三根圆脚呈三角形，比意大利 L 型更紧凑。 |

### Type K — 两圆脚 + U 形接地脚

| 属性 | 内容 |
|------|------|
| **形状** | 两根圆脚 + 下方 U 形接地脚 |
| **标准** | Danish 107-2-D1 |
| **额定** | 16A, 250V |
| **主要地区** | 丹麦、格陵兰 |
| **说明** | Danish 107-2-D1，接地脚在下方，呈 U 形。兼容 C 型插头。 |

### Type L — 三脚圆型一字排开

| 属性 | 内容 |
|------|------|
| **形状** | 三根圆脚水平排列在一条直线上 |
| **标准** | CEI 23-16/17 |
| **额定** | 10A/16A, 250V |
| **主要地区** | 意大利、圣马力诺、智利、突尼斯（部分） |
| **说明** | CEI 23-16/17，三脚水平排列，意大利标准。10A 和 16A 两种尺寸的插脚间距不同。 |

### Type M — 三脚圆型大三角形（15A）

| 属性 | 内容 |
|------|------|
| **形状** | 三根大圆脚呈等边三角形排列（比 D 型更大） |
| **标准** | BS 546 (15A) |
| **额定** | 15A, 250V |
| **主要地区** | 南非、印度、斯里兰卡、尼泊尔、中国澳门（部分） |
| **说明** | BS 546（15A），D 型的大电流版本，三脚更大。 |

### Type N — 三脚圆型三角形

| 属性 | 内容 |
|------|------|
| **形状** | 三根圆脚呈三角形排列 |
| **标准** | NBR 14136 |
| **额定** | 10A/20A, 250V |
| **主要地区** | 巴西、南非 |
| **说明** | NBR 14136，巴西与南非采用的 10A/20A 标准。基于 IEC 60906-1 国际标准。 |

### Type O — 三脚圆型三角形（泰国标）

| 属性 | 内容 |
|------|------|
| **形状** | 三根圆脚呈三角形排列 |
| **标准** | TIS 166-2549 |
| **额定** | 16A, 250V |
| **主要地区** | 泰国 |
| **说明** | TIS 166-2549，泰国专用标准。同样基于 IEC 60906-1，与 N 型类似。 |

## 电压与频率体系

全球民用电网主要分为两大体系：

| 体系 | 电压 | 频率 | 主要插头型号 | 覆盖区域 |
|------|------|------|------------|---------|
| **北美体系** | 100–130V | 60Hz | A, B | 北美、中美、部分南美、日本、菲律宾 |
| **欧洲/国际体系** | 220–240V | 50Hz | C, E, F, G, H, I, J, K, L, M, N, O | 欧洲、亚洲、非洲、大洋洲、部分南美 |

> ⚠️ **矛盾标注：双电压国家**
> 部分国家同时存在两种电压体系（如巴西 127V/220V、日本 100V 50/60Hz 分区域、利比亚 127V/230V）。出口充电桩产品时需特别注意目标国家的具体电压区域分布。

### 特殊频率情况

- **日本**：100V，东部（东京）50Hz、西部（大阪）60Hz——全球唯一全国分频率的国家
- **韩国**：220V 60Hz——使用欧洲体系插头（C/F）但频率为 60Hz（受美国影响）
- **沙特**：220V/230V 60Hz——使用英标 G 型插头但频率为 60Hz

### 随车充（IC-CPD）的特殊要求

根据 [[concepts/standard-iec-62752]]（IEC 62752:2024），IC-CPD 产品的一端连接车辆充电接口，另一端插入民用电源插座。因此：
- 随车充产品需根据出口国家提供对应型号的插头
- 插头必须满足目标国认证要求（如 CE、CCC、UL 等）
- 电压/频率必须与目标国电网匹配
