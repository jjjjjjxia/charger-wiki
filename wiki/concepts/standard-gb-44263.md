# GB 44263-2024 电动汽车传导充电系统安全要求

> **类型**: concept (standard)
> **创建时间**: 2026-07-22
> **最后更新**: 2026-07-22
> **来源**: [[standards/gb-44263-2024|GB 44263-2024 全文]]
> **标签**: #国标 #强制性标准 #安规 #充电系统

## 摘要

GB 44263-2024 是**强制性国家标准**，规定了电动汽车传导充电系统的总体安全、充电接口安全、交流充电安全、直流充电安全要求及试验方法。2024-07-24 发布，**2025-08-01 实施**。与 [[concepts/standard-gb-39752]] 配套——GB 39752 管"供电设备安全"，本标准管"充电系统安全"（含供电设备与车辆之间的系统级交互）。实施前提：供电设备符合 GB 39752、电动汽车符合 GB 18384。

### 适用范围

- 电动汽车**交流充电系统**和**直流充电系统**
- 供电网侧额定电压 ≤ **1000V AC** 或 **1500V DC**
- 汽车侧额定最大电压 ≤ **1000V AC** 或 **1500V DC**
- 也适用于电动汽车**充放电系统**中充电的安全要求
- **不适用**：维护相关安全要求、顶部接触式充电等自动充电系统

### 总体要求（第5章）

#### 充电模式使用条件

| 规定 | 内容 |
|------|------|
| 模式 1 | **不应使用**模式 1 对电动汽车充电 |
| 模式 2（10A 插头） | 输出电流 ≤ **8A AC** |
| 模式 2（16A 插头） | 输出电流 ≤ **16A AC** |
| 模式 2（32A 插头） | 输出电流 ≤ **32A AC** |
| 车辆适配器 | 非限制场所不应使用不符合国标的适配器 |

> 🔗 模式定义详见 [[concepts/charging-modes]]。国标明确**禁止模式 1**，与 IEC 各国限制差异情况一致。

#### 实施前提

- 供电设备须符合 **[[concepts/standard-gb-39752|GB 39752]]**
- 电动汽车须符合 **GB 18384**（电动汽车安全要求）

### 充电接口安全（第6章）

#### 6.1 充电接口防护等级

| 场景 | 防护等级 |
|------|---------|
| 连接方式 B/C，车辆插头与插座耦合 | **IPXXD** |
| 模式 3，连接方式 A/B，供电插头与插座耦合 | **IPXXD** |

#### 6.2 充电接口温度保护

**交流充电接口**：
- 连接方式 A/B，最大充电电流 > 16A AC → 须具备**供电插座**温度保护
- 三相交流，最大充电电流 > 32A AC → 须具备**车辆插头**温度保护
- 车载充电机最大充电电流 > 16A AC → 电动汽车须具备**车辆插座**温度保护

**直流车辆接口**：
- 直流供电设备须具备**车辆插头温度监测**，异常时降功率或故障停机
- 电动汽车须具备**车辆插座温度保护**

### 交流充电安全（第7章）

#### 7.1 系统设计安全

| 功能 | 要求 |
|------|------|
| **控制导引电路** | 模式 2 符合 GB/T 18487.1-2023 A.1.2；模式 3 符合 A.1.1 |
| **充电电缆载流检测** | 电动汽车通过检测点3与PE间电阻确认电缆额定容量，充电电流不超过供电能力与线缆载流值二者较小值 |
| **设备供电能力声明** | 通过 **PWM 信号占空比**告知可供电能力（符合 GB/T 18487.1 表A.2） |
| **接口锁止** | 充电电流 > 16A AC 时，供电插座/车辆插座须可靠锁止 |
| **触点粘连检测** | 接触器粘连时结束停机发出告警（单相L/三相L1L2L3任一） |
| **短路保护** | 能量传输前短路→不能充电；传输中短路→停止充电 |

#### 7.2 充电异常保护

| 异常类型 | 保护动作 |
|---------|---------|
| 设备侧 CC 回路异常（供电接口断开） | 传输前不能充电；传输中停止充电 |
| 车辆侧 CC 回路异常（S3断开/接口断开） | 停止充电 |
| 设备侧 CP 回路异常（CP断线/接地） | 传输前不能充电；传输中停止充电 |
| 保护接地连续性丢失 | 停止充电 |
| 车辆开关 S2 断开（检测点1 = 9V） | 停止充电 |
| 车辆侧 CP 回路（PWM中断） | 停止充电 |
| **供电网断电** | 1s 内输出端子电压 ≤ **30V AC** 或储能 ≤ **0.2J** |
| **输出过流** | 超过 PWM 对应最大电流/元器件承载能力 → 停止充电 |

### 直流充电安全（第8章）

#### 8.1 系统设计安全

| 功能 | 要求 |
|------|------|
| 控制导引电路 | GB/T 20234.3 接口→符合附录A 或 GB/T 18487.1 B.2/B.3；GB/T 20234.4 接口→符合 C.2/C.3 |
| 短路保护 | 检测到短路→故障停机+告警 |
| **电容耦合** | ≤500V DC：总电容 ≤ 0.5μF；>500V DC：储能 ≤ 0.2J 或双重/加强绝缘 |
| **泄放电路** | 闭合泄放开关后 **1s 内**输出电压降到 **60V DC** 以下 |
| **绝缘监测** | 能量传输阶段持续监测；Rimd ≤ Uimd × 100Ω/V 视为绝缘故障→停止充电 |
| 接口锁止 | 绝缘自检至能量传输结束保持电子锁可靠锁止 |
| 触点粘连检测 | 引用 GB 39752 中 8.1.7 |

#### 8.2 充电异常保护详细参数

##### §8.2.1 通信超时保护

| 条件 | 供电设备响应 | 车辆响应 |
|------|------------|---------|
| 输出电流 ≤ 200A | **2s 内**电流降至 ≤ 5A 并断开 K1/K2 | 5s 内断开 K5/K6 |
| 输出电流 > 200A | **3s 内**电流降至 ≤ 5A 并断开 K1/K2，电流下降速率 ≥ 100A/s | 同上 |

> GB/T 20234.4 接口系统按 GB/T 18487.1 表 C.14 规定。

##### §8.2.2 车辆侧 CC1 回路异常

- 车辆接口由完全连接变为连接不可靠 → 电动汽车触发**紧急停机**
- GB/T 20234.3 接口：**300ms 内**断开 K5/K6
- GB/T 20234.4 接口：按 GB/T 18487.1 表 C.16 规定

##### §8.2.4 设备侧 CC1 回路异常

| 阶段 | 供电设备响应 |
|------|------------|
| 能量传输前 | 不能充电 + 告警 |
| 能量传输中 | **紧急停机** + 告警；GB/T 20234.3 接口：**30ms 内**电流降至 ≤ 5A，**100ms 内**断开 K1/K2 |

##### §8.2.5 直流供电回路异常

- 绝缘自检阶段检测绝缘故障、短路故障、车辆侧充电回路电压异常
- 车辆接口电压须在电子锁解锁前降到 **60V DC** 以下
- GB/T 20234.3 接口：**2s 内**断开 K1/K2

##### §8.2.6 车辆供电回路异常

- 预充电阶段检测车辆接口电压异常（误差 > 5% 或不在正常充电范围）
- 触发故障停机 + 告警
- 车辆接口电压须在电子锁解锁前降到 60V DC 以下
- GB/T 20234.3 接口：**2s 内**断开 K1/K2

##### §8.2.7 输出过压保护

| 条件 | 响应 |
|------|------|
| K1/K2 外侧电压 > 最高输出电压持续 > **400ms** | 故障检测时间 ≤ **1s** |
| 输出电流 ≤ 200A | **2s 内**电流降至 ≤ 5A 并断开 K1/K2 |
| 输出电流 > 200A | **3s 内**电流降至 ≤ 5A 并断开 K1/K2，速率 ≥ 100A/s |

##### §8.2.8 输出过流保护

| 条件 | 响应 |
|------|------|
| 需求电流 ≥ 30A，实际 > 需求 **10%** 持续 **1s** | **500ms 内**故障停机 |
| 需求电流 < 30A，实际 > 需求 + **3A** 持续 **1s** | 同上 |

##### §8.2.9 负载突降保护

- 供电回路瞬时输出过压不超过：负载突降前最高允许充电总电压的 **110%** 与最高允许充电总电压 + **50V DC** 二者较大值
- 负载突降后 **10ms 内**的瞬态电压忽略不计

### 安全测试项目清单（表1）

**交流充电系统**测试项目（供电设备侧）：
充电接口防护等级、交流充电接口温度保护、控制导引电路、设备供电能力声明、接口锁止、触点粘连检测、短路保护、设备侧CC回路异常保护、设备侧CP回路异常保护、供电网断电保护、输出过流保护

**交流充电系统**测试项目（车辆侧）：
充电接口防护等级、交流充电接口温度保护、控制导引电路、充电电缆载流能力检测、接口锁止、车辆侧CC回路异常保护、车辆侧CP回路异常保护

**直流充电系统**测试项目：
充电接口防护等级、直流车辆接口温度保护、控制导引电路、短路保护、电容耦合、泄放电路、绝缘监测、接口锁止 等
